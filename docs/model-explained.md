## 1. 一句话口径

按基准价格买入 1 股，之后十年逐年领取现金分红，并在第十年末按预测 EPS 乘退出 PE 卖出，求使这 11 笔现金流现值等于买入价的年化折现率。
不假设分红复投，不计红利税、交易费用、未来回购与稀释。

## 2. 公式

```text
已知（输入）：
  P0    买入基准价（有明确日期）
  E0    正常化的起始年度预测 EPS（第一年年初水平）
  g(t)  第 t 年的 EPS 增速（逐年数组优先）
  d(t)  第 t 年分红率（逐年数组优先）
  旧数据按 stageYears 展开 early / late / payout
  M     第十年完整股权口径退出 PE
  h     研究者设定的必要回报率（研究门槛，不是模型解出的值）

递推（t = 1, 2, …, 10）：
  g(t)  = growthRates[t-1]，或兼容两阶段路径
  E(t)  = E(t-1) × [1 + g(t)]
  D(t)  = E(t-1) × d(t)         分红按【上一年度】EPS 估算
  P10   = E(10) × M             第十年末卖出所得
  CF(t) = D(t)          (t < 10)
  CF(10)= D(10) + P10

求解（二分法，迭代 160 次，残差 < 1e-8）：
  P0 = Σ[t=1…10] CF(t) / (1 + r)^t      →  r = 基准 IRR

派生：
  相对回报要求差额 = r − h                      单位：个百分点
  达标参考买入价   = Σ[t=1…10] CF(t) / (1 + h)^t  该组现金流下 r = h 的价格
```

- 三个情景（悲观 / 基准 / 乐观）各自独立求 IRR，基准是中间那组假设；差额全部以「基准情景」计算。
- `D(10)` 使用 `E(9)` 是派息滞后一年的时序近似；同年盈利与除息后出售价值可以同时存在，不能将这个约定解释为防止重复计算的必要条件。
- 首年分红默认用预测起点 `E0 × d`；已公告且买入后仍享有的派息须核对除息日，并替换同一笔预测金额。

- 完整首年覆盖可用 `firstDividend`；单笔部分已知用 `firstDividendParts`，两者互斥。保存已知金额、来源、除息日和被替换预测比例：首年现金 = 原预测 × (1 − 替换比例) + 买入日在除息日前仍享有的已知金额。除息日及之后买入不享有该笔股息，但仍扣除对应预测，防止重复计算。比例是研究近似，须披露依据；实际派息时间仍按年度近似。当前字段不支持多笔已知股息数组，不得擅自叠加。

## 3. 七类数字的取数位置

| 参数 | 从哪里来 | 典型做法 |
| --- | --- | --- |
| 买入价 P0 | 有明确日期的可核实收盘价 | 只用港股/成交币种价格，不混用 A/H，不把过期行情称为当前价 |
| 起点 EPS E0 | 起始年度正常化归母净利润预测 ÷ 总股本 | 结合最近一期财报与后续经营假设推导，不机械年化半年报 |
| 增速 g1 / g2 | 原报告对该公司经营节奏的判断 | 拆成「前三年修复/增长」和「后七年趋于常态」两段，避免十年单一高增速 |
| 分红率 d | 公司分红规划、历史分红率、现金流覆盖能力 | 规划底线不作永久承诺；需用经营现金流与资本开支交叉检验 |
| 退出 PE M | 第十年的成熟期估值假设 | 三档给出；周期股取低档，消费/平台取中高档 |
| 必要回报率 h | 风险分档（见第 4 节） | 主观投资门槛，按生意可预测性、现金流波动与资产负债表风险分档，不由模型解出 |
| 币种 | 与股价同一币种 | 港股标的须把报表币种利润按固定汇率折成港元再算 EPS，并在 `model.fx` 中声明（见第 8 节） |

## 4. 必要回报率 h 的分档依据

`h` 不是由 CAPM 或 WACC 算出来的，是按「生意可预测性 + 现金流波动 + 资产负债表风险」主观分档；当前标的取值 8.0%—14.0%。
`h` 在数据文件中以 `requiredReturn` 保存，由 `requiredReturnReason` 记录该档理由。档位只为安排研究优先级，不是对生意质量的评分，也不得为提高排名而下调。

## 8. 币种口径与自动校验
