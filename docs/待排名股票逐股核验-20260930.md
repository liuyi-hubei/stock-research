# 25只待排名股票逐股核验

> 首轮历史记录：下方14只排名、23只暂停的状态已被续核结论替代。当前逐股判断见[剩余23只股票续核结论](剩余23只股票续核结论-20260930.md)，不删除首轮发现的现金风险。

核验日期：2026年9月30日。本轮优先用妙想检索定位公司公告，再逐项检查原始财务表；携程首次检索只返回年报，缩小同一问题重试后取得2026H1原始公告。行情和模型盈利、增长、分配、退出倍数均保留原报告基准，不是本轮刷新股价。

## 审核范围与结论

本轮复核的是导致暂停排名的关键现金、资本及正常化约束，不表示所有会计科目或十年假设完成审计。25只逐项检查后，茅台和美的获得历史现金起点支持，恢复为“部分核验”参与条件情景排名；其余23只仍有具体阻断项。全研究池37只，当前排名14只、待核验23只。恢复排名不等于推荐买入，更不等于未来分配已获公司承诺。

所有金额除明确港元/美元外均为人民币亿元；合并与母公司不能相加。经营现金减购建支出只是中间桥接，不是最终普通股现金；利息、租赁、少数股东、净偿债及承诺需按实际分类再检查。半年数据不直接年化，跨年资本承诺不一次性扣为当期支出。
