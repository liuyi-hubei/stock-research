版本：2026-10-24-r2。本文件是协作入口，不维护第二套写作规则。

## 必须阅读与优先顺序

1. 仓库根目录[AGENTS.md](../AGENTS.md)：工程、写入和发布边界。
2. [大师思维技能](../.agents/skills/master-thinking/SKILL.md)及所需投资者模型。
3. [个股研究报告写作规范](../.agents/skills/master-thinking/references/个股研究规范.md)：唯一写作主规则，包含最新六章、排除清单、未来现金与估值边界。
4. [结构与渲染协议](research-framework.md)、[数据与收益计算](research-method.md)；多人任务再读[协作与交接](multi-agent-workflow.md)。

写作要求冲突时以上述“写作规范”最新版本为准；历史实施记录不作新任务指令。规范决定写什么，结构协议决定保存和展示方式，收益引擎不负责判断假设是否可信。

## 本地 agent 与 ChatGPT Work 共同维护

- 开始前检查当前分支、提交及未提交差异；可安全同步时只做快进，不覆盖其他人的成果。
- 提交任务说明：目标股票/市场、是否新取证、允许修改的文件、是否允许更改参数/模型状态及是否允许推送。
- 报告先形成中文Markdown，存入reports/stocks；网站采用结构化报告时，正文唯一源为data/research/CODE.js，再按CODE生成Markdown，不能两份分别维护。有结构化源的标的，归档由脚本派生、只作离线存档与校验锚点，交付以页面为准，不把md当成果展示。
- 一只股票同一轮一个写入者；共享数据、渲染、缓存和生成文件由一位集成人串行处理。无需并行时不强开子agent。
- 交付列明事实来源、继承/新取证日期、假设与缺口、改参范围、检查结果。不能用“完成模板”代替研究完成。
- 在线Work必须有仓库读取权限；不能读取时提供所需规则文件，不声称已同步。GitHub更新不会自动刷新所有设备的已安装插件，需用技能清单核对镜像。
- 推送main可能触发服务器北京时间18:00拉取，推送属于发布相关动作，须有用户授权。

## 可复制给其他 agent / Work 的任务提示

> 请先读取仓库AGENTS.md、docs/个股研究报告规范建议.md、大师思维SKILL.md及其references/个股研究规范.md，并按所需模型研究指定公司。以段永平为主，巴菲特/芒格检验，其余三位辅助；输出最新六章。过去仅作参考，未来现金无法形成可信量级就明确暂不能合理估值，不强填增长率或买点。不要把旧模型阈值当可靠建议。按任务授权范围更新正文、归档和相关页面，交付证据、参数变动与测试记录；未经授权不推送或发布。
