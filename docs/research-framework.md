## 当前协议与写作入口（2026-10-24-r2）

用户已确认[个股研究报告规范建议](个股研究报告规范建议.md)的新布局：投资结论、商业模式、企业文化、安全边际与估值、其他思维观点、关键风险与后续验证。000568使用`company-study-v2`与summary/business/culture/valuation/perspectives/risks六个ID；下方evidence-first-v1结构继续用于尚未迁移的002555、002714，不强制复用旧章节标题。两种布局共用原财务对象与IRR引擎，模型/资格和数据核验规则不变。安全边际分析公司未来利润/现金清晰度及必要回报率依据，不替用户判断个人能力圈。

当前新报告版本：`company-study-v2`；旧报告兼容版本：`evidence-first-v1`。本规范落实用户批准的六章研究框架，与 [研究与更新规则](research-method.md)、[多 agent 协作规范](multi-agent-workflow.md) 配套使用。框架用于组织证据、推导和缺口，不增加估值模型，不自动授权更改参数或排名。000568/002555/002714已接入结构试点，不代表完成新一轮经营取证；其他标的须逐股迁移。

写作落地同时执行[个股研究报告规范建议](个股研究报告规范建议.md)：段永平第一主线，巴菲特/芒格第二层检验，其他三位辅助；分析商业模式、企业文化和估值，按需做整家公司所有权检验，不使用闯关式标题。下表六章承载这条主线，而非六位等权点评；结论组件保持现状，关键认识不足不能靠条件参考价给出积极买入判断。

## 一、六章正文

### 分析先行，证据随论证组织（2026-10-24）

以项目统一的“大师思维”为分析核心：理解商业模式和文化，检验护城河与所有者收益，倒推失败路径及激励，检查组织执行、持有人生存和价值/时机条件；再把财报、公司公告、行业、研报及行情证据放入对应问题。六位视角是思考工具，不要求写六份人物点评，也不先给结论后挑数据。

保留用户认可的投资结论结构。写作内容以技能内个股研究规范为准，下表为旧版协议兼容说明，不用于新报告定标题。每个主要判断遵循“命题→公司专属证据→解释与反证→对盈利/现金/估值的影响”。避免用缺口清单代替分析，也不能以模型完成或券商评级代替独立判断。来源注明日期与可信层级，但取数过程、方法迁移记录不反复打断正文。

一项证据只在最相关位置充分展开，其他章节简短回指；研报盈利表集中在盈利章，渠道观察服务于生意与经营路径，价格/分红服务于现金与估值，跟踪章只保留关键指标和偏差记录。已整合正文的报告设置`integratedNarrative: true`，禁止页面/归档再自动拼接旧行业公司段落、完整预测note或全部跟踪卡片；原财务对象不删除，模型及数值表仍从同一来源生成。未迁移报告保持原行为。

仅编辑结构时沿用各项原始取证日，不借新方法日声称数据最新或调参。需要新增数据时另行妙想优先取证，依据新证据重审判断；不把框架用作固定答案模板。

新报告company-study-v2采用固定映射：

| 展示章节 | ID |
| --- | --- |
| 投资结论 | summary |
| 商业模式 | business |
| 企业文化 | culture |
| 安全边际与估值 | valuation |
| 其他思维观点 | perspectives |
| 关键风险与后续验证 | risks |

以下表格只适用于未迁移的evidence-first-v1。不要根据标题自行改ID；status不代表模型状态，forecast也不证明预测可靠。

| 章 | ID | 必须回答的问题与交付内容 |
| --- | --- | --- |
| 1. 投资结论 | `summary` | 当前能判断什么、不能判断什么？写出核心论点、反证、关键假设、研究状态和失效条件。引用现有模型时注明价格日、实际财报期及条件，不把排名、正差额或模型可计算当作买入结论。 |
| 2. 生意与护城河 | `status` | 谁付钱、为何购买、收入和成本怎样形成？竞争优势依靠什么、能维持多久、有哪些侵蚀证据？统一讨论客户价值、定价权、竞争、资本回报与资本配置，不按五位大师逐人点评，不虚构本人观点或持仓。 |
| 3. 真实盈利基准 | `forecast` | 当前法定盈利、扣非盈利和研究正常化盈利差在哪里？列示分部、税、少数权益、一次性项目、股本和币种的桥接；说明基准可识别程度。无法建立基准就写缺口，不强填 EPS。 |
| 4. 经营驱动的未来路径 | `path` | 近 1—3 年的量、价、成本、产品、份额、投产或渠道变化怎样进入利润？第 4—10 年的市场空间、竞争、再投资回报和资本约束怎样支持收敛？分别说明悲观、基准、乐观的机制、触发条件和反证。 |
| 5. 股东现金与估值 | `valuation` | 利润如何经过营运资金、资本开支、债务、租赁、监管资本与母公司汇付形成普通股可分现金？说明分红时序、每股权益、退出状态和门槛；收益结果只引用现有 `shareholder-irr-v1`。 |
| 6. 跟踪指标与预测偏差 | `risks` | 用 3—5 个关键指标追踪论点，注明口径、来源、频率、触发条件及对应假设。维护预测偏差台账，记录原判断与后来事实的差异、原因和后续处理，保留旧判断。 |

每章须有实质内容；投资结论可省略标题下导语，不重复说明分析流程和改写记录，其余章节保留明确导语。证据不足时标示缺口、影响和补证动作，不能用六段通用提醒凑齐章节。统一问题并不意味着统一答案：银行核监管资本与普通股回报，保险核偿付能力与可分配利润，周期企业核跨周期量价成本，困境企业先核生存、偿债和稀释。

### 真实盈利与经营路径的约束

盈利桥接应保留原始财报期间、会计口径、币种和单位，解释从集团到归母、从总额到每股的过程。非现金费用也可能代表真实经济损失，不能全部加回；不能只剔除损失而保留同类收益。半年报不得直接翻倍作为年度基准，低增长率不能掩盖周期高点或不可持续利润起点。

近 1—3 年优先给出可检验的经营驱动；第 4—10 年解释成熟状态与达到该状态的条件，不任意指定恢复、投产或派息年份，不把所有企业统一设为三年后稳定增长。低增速本身不等于保守，平滑曲线与十个逐年数字也不等于完成经营预测。未完成取证的路径只能称条件假设，不能称可靠预测。

正常化不是挑选好年份，也不是将历史均值直接用作未来。尚不能解释跨周期价格、成本、资本与归母权益的企业，应撤回缺乏依据的基准。明确区分公司披露的历史数、管理层目标、券商预测和本研究假设；预约披露日期不是财报实绩日期。

### 股东现金与唯一收益模型

合并经营现金减购建现金只是观察差额，未经租赁、投资、偿债、受限资金、维护与扩张投入及母公司可分配能力桥接，不能标为普通股自由现金或分红上限。集团与母公司现金不得相加；融资流入不是经营创造，租赁与营运资金不得重复扣除。金融企业使用适合其业务的资本约束，不能机械套工业企业差额。

未来分红未知不得填零，零股息压力测试不能代替基准；分红规划、董事会方案、批准与已实施须分别说明。首年现金须核买入后的除息权利，沿用现有 `firstDividend` / `firstDividendParts` 的替代规则，不重复添加完整年度预算或已除息现金。未注销回购不提前缩股，不同时计算回购增厚和额外现金收益。

现有模型算式与时序保持不变：以基准价买入一股，逐年领取现金分红，第十年末卖出，分红不复投，使用共同引擎求税费前、交易币种的十年股东现金流 IRR。沿用现有 EPS 递推、以前期 EPS 估计当期派息、首年覆盖、退出 PE 和参考价算法；本框架不调整任何计算约定。情景参数和输出引用原股票数据及共同引擎，不在新框架中复制一套财务参数、手算IRR或自动增加第二套估值、概率加权收益与评分。现金流不能形成可信量级时不要新增DCF；旧演算明确条件性质，不能当可靠买点。

退出倍数须与第十年竞争、增长、资本回报和风险相容，回报要求须说明主观依据。不得为改善排名倒推盈利、增速、分红率、退出倍数或门槛。单项敏感性是条件扰动，不是概率区间，也不能补足基准证据。

### 跟踪与偏差台账

每股选择 3—5 个能区分情景的指标，而非罗列全部财务比率。每项至少写明：指标名称、统计口径、历史观察日及值或未取得状态、来源定位、跟踪频率、触发条件、关联论点及触发后的核查动作。阈值未经取证只能标为研究假设，不编造精确警戒线。

预测偏差台账至少包含以下列：

| 原记录日期与预测期 | 原判断及假设 | 后来实际值、期间及来源 | 差异与原因 | 对基准/路径/现金/状态的影响 | 处理人及复核日期 |
| --- | --- | --- | --- | --- | --- |
| 使用当时真实记录 | 保留原值和原措辞 | 无新实绩则写尚未到期或未取得 | 分开口径变化、外部变化和判断错误 | 不因偏差自动调参或恢复排名 | 指向可追溯的研究记录 |

历史证据重组时可以记录已知矛盾和待核项，但不得倒填当时并未作出的预测，不能将事后重述当作预测命中率。

## 二、证据分层与来源定位

每个重要判断都须区分以下四层，并写明它支持什么、不能支持什么：

- **事实**：可定位的原始披露或有边界的外部观察，保留期间、发布日期、主体、单位与口径。优先交易所/公司公告，其次正式投资者关系记录；渠道样本不代表全国，转载不等于已核原文。
- **推导**：列出输入、计算或逻辑桥接及限制，读者能够从事实复核到结论。
- **假设**：明确是谁的假设、适用期、触发条件、反证和对结果的影响，不伪装成公司承诺。
- **缺口**：未取到什么、是否阻断基准、需要何种证据、谁负责跟进。来源缺失不以模板或模型运行成功补齐。

关键断言须指向该股票既有 `stock.sources`，同时在正文或证据文字中提供公告/报告名称、披露日期、页码、表名或段落定位，以及期间、币种、单位。`sourceRefs` 只完成来源关联，不能代替页码与口径说明。继承历史来源须注明“继承，未在本轮重新取证”；未取得原文就如实说明，不宣称本轮逐项核验。

后续需要新取证时，行情、估值和财务表优先 `mx-finance-data`，公告、新闻及经营事件优先 `mx-finance-search`，再回到原始披露核验。不使用接口直接生成成品研究报告。当前仅规范编写及历史重组不构成金融数据更新。

## 三、研究三状态与排名边界

研究状态描述证据是否支持基准；模型状态控制是否计算；排名资格由现有 `model.rankingDecision` 和共同引擎资格逻辑决定。三者不得混用，不能按章节完整、文字数量或状态标签自动恢复排名。

| 研究状态 | 定义 | 计算与排名处理 |
| --- | --- | --- |
| `ready` | 关键证据支持一个可解释、可检验的基准，盈利、经营路径与股东现金之间的主要约束已说明；仍有不确定性 | 不等于预测保证或买入建议，不自动获得排名资格；须另有逐股资格依据及审核记录。规范允许，当前三股试点不使用。 |
| `conditional` | 有可解释的条件路径，但重要假设存在分歧或关键环节尚待补证 | 明示条件、反证与缺口；仅在现有模型仍有效时沿用条件演算。本标签不修改原资格，不自动恢复或取消排名，不能借此复活已撤回模型。 |
| `pending` | 无法建立有依据的盈利、现金分配或必要权益基准 | 对需要撤回的模型按既有协议设置 `model.status = 'pending'`、写 `pendingReason`、清空情景数组、回报要求置 `null`；`evaluate` / `sensitivity` 返回 `null`，排除排名，停用试算与旧情景展示，保留事实和来源。无结果不是零收益或引擎错误。 |

新框架的 `reviewState` 是研究说明，不能单独驱动现有引擎。若发现应撤回而现有模型仍计算，worker 应交出阻断证据与最小变更建议，由具有参数/状态权限的集成人处理；不能只改说明标签后声称模型已经停用。

状态升级必须有新增或重新核验的证据、逐项缺口处理和明确审核记录。方法改版不构成升级依据，`ready` 也不能覆盖现有 `pending`。条件演算是否保留与排名是否允许均须逐股审定，不批量统一放行。

## 四、结构化交付协议

每股使用独立文件 `data/research/CODE.js`，以 `window.RESEARCH_FRAMEWORK[code]` 注册。它保存六章正文与证据关系，原股票对象继续作为财务、模型、股本、价格、来源和资格的唯一数据源。共享校验与渲染在 `assets/research-framework.js`；四入口加载及Node侧 `docs/research-framework-files.mjs` 由集成人维护。

顶层字段固定如下：

| 字段 | 约定 |
| --- | --- |
| `version` | 新报告为company-study-v2；未迁移报告为evidence-first-v1，均区别于收益模型版本。 |
| `code` | 股票代码字符串，保留前导零，与原股票对象一致。 |
| `methodReviewedAt` | 方法审阅日期；不得替代行情日、财报期间、盈利假设日期或 `researchDate`。 |
| `reviewState` | 三状态语义按上文；本轮试点实际值只使用 `'conditional'` / `'pending'`。 |
| `businessType` | 业务类型及分析所需分类，不自动映射增速、退出倍数或门槛。 |
| `summary` | 简要结论与证据边界，和首章一致，不另存估值参数或收益结果。 |
| `sections` | 固定六项；company-study-v2为summary/business/culture/valuation/perspectives/risks，evidence-first-v1为summary/status/forecast/path/valuation/risks。 |

每个section必填id、title、intro和非空blocks；标题按对应版本，summary的intro可为空。每个block恰有一个类型键：`h3`或`p`为非空文本，`bullets`为文本数组，`table`为`{head:文本数组,rows:等列数文本行,note?:文本}`，或使用 `evidence` 对象。后者字段为：

```text
evidence: {
  claim,        // 所要判断的具体命题
  basis,        // 事实依据、定位与推导；标明继承或本轮核验
  counterpoint, // 反证、不同解释或约束
  state,        // 只能为已披露事实 / 研究推导 / 情景假设 / 待补证，不是模型资格
  sourceRefs    // 0-based stock.sources 索引数组
}
```

`sourceRefs` 只接受非负整数且必须小于对应 `stock.sources.length`；不能把页面上从 1 开始的来源序号直接写入。没有可关联来源时允许空数组，但正文必须明确未取证或缺口，不能标为已核事实。来源数组调整由集成人核查受影响索引，禁止 worker 擅自重排共享来源后留下错误关联。文本、列表、表格的具体载荷结构以父 agent 的渲染协议为准，不在本文另立不兼容格式。

框架中允许解释历史参数及其局限，但不得建立可供另一套计算使用的财务参数副本；数值展示应来自原数据/同一引擎，历史引文须注明期间与性质。

## 五、三股试点与未迁移边界

试点只覆盖 `000568` 泸州老窖、`002555` 三七互娱、`002714` 牧原股份。后续迁移仅重组已有历史证据、推导、假设和缺口，不重新取数、不调整行情或财报期、不修改原模型算式、参数、门槛和资格，不借方法审阅刷新研究日期。

- `000568`、`002555` 使用 `conditional`：已有路径仍有现金与假设边界，不因改为六章就称可靠预测或自动升级排名。
- `002714` 使用 `pending`：既有旧盈利锚和零分红路径已经撤回，不恢复旧情景，不任意设定盈利或恢复派息年份；同一引擎继续返回 `null`。
- 三股均无 `ready`；其他股票未迁移，保留各自原研究、日期及资格，不宣称全池完成新框架或最新财报复核。
