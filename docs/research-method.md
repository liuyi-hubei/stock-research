# 研究与更新规则

## 更新触发

不设置定时抓取。财报或重要公告发布后，由用户手动发起一次更新。

## 数据优先级

1. 交易所和公司公告、定期报告；
2. 公司业绩说明会及正式投资者关系记录；
3. 有明确日期和口径的批价、库存、动销资料；
4. 券商和媒体资料仅作为线索，不替代原始披露。

## 每次更新必须完成

- 核对最新实际财报与上一版预测的差异；
- 更新收入、净利润、每股收益和自由现金流假设；
- 分开记录事实、推断和主观假设；
- 重算悲观、基准、乐观情景；
- 按更新日最新可核实收盘价，更新该标的十年股东现金流 IRR、达标参考价、相对回报要求的差额，以及失效条件；
- 保留历史版本和变更说明。

## 模型口径

全池统一采用 `shareholder-irr-v1`：买入 1 股后逐年领取现金分红，第十年末卖出，按年度现金流求税费前年化 IRR；分红不假设复投。逐年 EPS 增长、分红时序、退出 PE、主观回报要求、达标参考价和价格／财报／假设日期均见各股报告与 `assets/shareholder-model.js`。模型不自动计入红利税、交易费用、未来回购或稀释。

首页排序为「基准 IRR − 研究回报要求」降序，相同差额时悲观 IRR 较高者优先；排序与披露要求以 `AGENTS.md` 的“十年投资收益模型与页面规范”为准。每份报告须写明起始盈利、增长率、分红率、退出 PE、研究回报要求和各数据日期；不得再使用旧 `baseReturn`（分红复投期末财富 CAGR）口径，也不得把 CAGR 与 IRR 混排。

## 新增个股

新增股票默认写入 `data/additional-stocks.js`，基础股票仍在 `data/stocks.js`；按既有数据结构补齐事实、来源和模型字段，并同步维护 `reports/stocks/` 归档。首页只展示基准年化排名前十只，全部标的在个股研究列表展示。

Markdown 归档不会自动成为网页。补充报告须登记阅读入口；华能蒙电全面体检阅读页由 `node docs/render-archive.mjs` 生成。对已有网页但缺少归档的标的，可运行 `node docs/export-stock-archive.mjs 股票代码` 导出当前数据快照；工具拒绝覆盖已有文件，也不会更新行情。
