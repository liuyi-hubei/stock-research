# 研究与更新规则

## 更新触发

不设置定时抓取。财报或重要公告发布后，由用户手动发起一次更新。

## 数据优先级

1. 交易所和公司公告、定期报告；
2. 公司业绩说明会及正式投资者关系记录；
3. 有明确日期和口径的批价、库存、动销资料；
4. 券商和媒体资料仅作为线索，不替代原始披露。

## 每次更新必须完成

- 核对最新实际财报与上一版预测的差异；
- 更新收入、净利润、每股收益和自由现金流假设；
- 分开记录事实、推断和主观假设；
- 重算悲观、基准、乐观情景；
- 按更新日最新可核实收盘价，更新该标的十年股东现金流 IRR、达标参考价、相对回报要求的差额，以及失效条件；
- 保留历史版本和变更说明。

## 模型口径

### 排名资格与情景可信度

排名用于比较条件研究情景，不代表十年预测已获验证。缺少公司十年预算、某一期资本支出后现金为负，不自动取消排名；须逐股交代资本、现金分配来源、未来假设及失效条件。`rankAssessment`保存模型类型、可信度、事实分析和研究条件，不能用统一文案替代。只有无法建立明确基准路径或必要权益口径时才保留演算而不排名。零股息模型可以作为终值型参与比较，但须明确100%依赖退出价值，不编造未来开始派息的年份。所有历史锚与当前事实分期标示，有限可信度不等于现价推荐。

全池统一采用 `shareholder-irr-v1`：买入 1 股后逐年领取现金分红，第十年末卖出，按年度现金流求税费前年化 IRR；分红不假设复投。逐年 EPS 增长、分红时序、退出 PE、主观回报要求、达标参考价和价格／财报／假设日期均见各股报告与 `assets/shareholder-model.js`。模型不自动计入红利税、交易费用、未来回购或稀释。公式推导、七类参数的取数位置、必要回报率分档依据，以及全池标的的参数与结果快照，见 `docs/model-explained.md`（由 `node docs/gen-model-explained.mjs` 从数据生成，不含手工维护的数量）。

这是项目唯一的收益口径。`reports/stocks/` 下的 Markdown 归档、个股详情页、首页榜单和 `docs/` 内的说明必须使用同一口径与同一计算函数，不得再出现「分红复投年化」「期末持股」「期末价值」「折现值」等表述；`node docs/validate.mjs` 会检查归档是否残留这些词。新增标的的归档初稿可用 `node docs/export-stock-archive.mjs 股票代码` 生成。

币种是硬约束：模型输出的价格、EPS、分红与期末卖出价值必须与股价同币种。港股标的的经营报表可能是人民币或美元，须先按固定研究汇率折成港元。每只港股模型在 `model.fx` 中声明报表币种、汇率、汇率来源与折算前的报表口径基准 EPS；`node docs/check-shareholder-model.mjs` 会校验换算是否一致，缺失声明或换算不匹配都会失败。新增港股标的时不要跳过这一步。

首页排序为「基准 IRR − 研究回报要求」降序，相同差额时悲观 IRR 较高者优先；排序与披露要求以 `AGENTS.md` 的“十年投资收益模型与页面规范”为准。每份报告须写明起始盈利、增长率、分红率、退出 PE、研究回报要求和各数据日期；收益只报 IRR，不再使用分红复投后的期末财富 CAGR，也不得把 CAGR 与 IRR 混排。

## 新增个股

新增股票默认写入 `data/additional-stocks.js`，基础股票仍在 `data/stocks.js`；按既有数据结构补齐事实、来源和模型字段，并同步维护 `reports/stocks/` 归档。首页只展示按基准IRR减研究回报要求排序的前十只已审核标的，全部标的在个股研究列表展示。

页面上的数量全部由数据推导，**不需要为了数量去改页面代码**：首页「跟踪公司」取 `db.stocks.length`，排行按钮「查看全部 N 只」仅计结果有效且未暂停排名的标的，报告列表仍保留全部公司。校验脚本的路由数与港股只数也是数出来的。增删一只标的实际要动的只有下面几项：

| 项目 | 是否必改 | 说明 |
| --- | --- | --- |
| `data/stocks.js` 或 `data/additional-stocks.js` | 必改 | 唯一的数据源；新增标的必须有 `model.version = "shareholder-irr-v1"`，否则模型校验脚本会直接失败 |
| 新增港股标的的 `model.fx` | 仅港股 | 在 `data/additional-stocks.js` 的 `HKD_MODEL_FX` 中登记报表币种、汇率与折算前基准 EPS，漏登记会在加载时抛错 |
| `reports/stocks/` 归档 | 必改 | 主报告与数据、参数审核、页面同步，缺失归档视为不完整交付 |
| 入口脚本的 `?v=` 缓存戳 | 必改 | 改完数据后同步提升 `index.html` / `reports.html` / `stock.html` / `industry.html` 中的版本号，否则浏览器会读旧数据 |
| `node docs/gen-model-explained.mjs` | 必跑 | 重出模型说明文档的参数表与排名表 |

Markdown 归档不会自动成为网页。补充报告须登记阅读入口；华能蒙电全面体检阅读页由 `node docs/render-archive.mjs` 生成。对已有网页但缺少归档的标的，可运行 `node docs/export-stock-archive.mjs 股票代码` 导出当前数据快照；工具拒绝覆盖已有文件，也不会更新行情。

## 逐年路径与参数审阅

执行 `AGENTS.md` 的“参数研究与一致性规范”。新增预测优先提供十年 `growthRates` / `payoutRates`，近期以经营驱动推导、远期有依据地收敛。旧数据仍按原两阶段路径计算，不能把新增模型能力表述为已经重做了27家公司的经营预测。

参数审阅显示盈利起点、经营路径、资本约束、每股口径和退出估值的证据缺口。资本收支未经核对时，不能声称增长和分红可同时兑现。新城发展因恢复派息年份未知暂停排名，原计算仅供条件演算核对，不能自行指定恢复年份。

详情页显示卖出所得现值占比与EPS十年倍数，并用同一模型做起始EPS上下20%、远期增速上下2个百分点、退出PE上下20%的单项压力测试；回报门槛上下1个百分点仅影响参考价及差额。这些不是概率预测。

运行 `node docs/sync-model-review.mjs` 同步归档的自动审阅区；运行 `node docs/gen-model-explained.mjs` 更新参数说明。自动审阅不覆盖人工正文，改变实际参数时仍须人工核对正文中的结论数值。

排名资格由 `ShareholderModel.eligibility` 读取 `model.rankingDecision`，需明确资格、证据状态（待补证/部分核验/关键假设通过）、理由和审核日；计算有效不等于研究通过，部分核验不得宣称十年资金约束全部验证。新增标的未审默认不入榜。使用`firstDividendParts`拆分首年已知/预测股息时，注明替换比例及除息权利，不能与完整首年覆盖同时使用，不能重复计息。

交付须运行两个生成脚本的`--check`、`docs/check-report-numbers.mjs`和`docs/check-publication.mjs`，连同既有模型、路由及归档检查。数字检查只覆盖明确模型结论，原始金融事实仍需人工核验；真实桌面/窄屏交互另行验证。全部检查通过也不等于授权发布。
