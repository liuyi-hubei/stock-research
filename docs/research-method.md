# 研究与更新规则

## 更新触发

不设置定时抓取。财报或重要公告发布后，由用户手动发起一次更新。

## 数据优先级

1. 交易所和公司公告、定期报告；
2. 公司业绩说明会及正式投资者关系记录；
3. 有明确日期和口径的批价、库存、动销资料；
4. 券商和媒体资料仅作为线索，不替代原始披露。

## 每次更新必须完成

- 核对最新实际财报与上一版预测的差异；
- 更新收入、净利润、每股收益和自由现金流假设；
- 分开记录事实、推断和主观假设；
- 重算悲观、基准、乐观情景；
- 更新十年分红复投收益率与失效条件；
- 保留历史版本和变更说明。

## 模型口径

页面中的十年模型按年度计算每股收益和现金分红，并假设分红按当年模型估值复投。模型暂不考虑红利税、交易费用、回购注销和股权稀释，正式研究报告应单独说明这些因素。

## 新增个股

在 `data/stocks.js` 的 `stocks` 数组中增加一个对象，即可自动出现在首页，并复用统一的个股研究页和估值模型。
