# 电力与能源行业研究

煤炭、火电、水电、核电与风光运营：从能源供需走向普通股现金回报

研究日期与口径：2026年10月1日；供需截至2026年8月，财务为2026H1，政策按原文发布日期

作者：刘益的复利研究室 · 独立研究

## 核心结论：同一条能源链，不同的利润方向

煤企赚资源与交付的价差，火电赚电价与燃料成本的价差，水电赚水文与成熟资产的现金，核电与风光则必须跨过建设、融资和市场电价的考验。能源安全和电气化创造长期需求，但不能保证每家公司的分红增长。研究重点不是笼统押注“能源上涨”，而是识别正常化成本、可靠电量、实现电价和真正归属普通股的现金。

## 一、先拆产业链：资源、发电与系统服务不是一种生意

单位、收入来源与现金权利，必须先讲清楚

| 环节 | 收入和竞争力 | 不能混淆的事情 |
| --- | --- | --- |
| 煤炭开采 | 可售吨数 × 实现煤价，减完整开采、运输与资源成本 | 储量不等于可交付产量；自产煤不等于贸易煤 |
| 火电与供热 | 上网电量价差、供热、符合条件的容量及辅助服务 | 煤价下降不等于利润必升；发电量不等于上网电量 |
| 水电与核电 | 电量、电价与长期资产运行，扣除全生命周期投入 | 资产寿命长不等于无维护、融资或市场价格风险 |
| 风光运营 | 有效上网电量、实现电价和适用机制结算 | 装机增长不等于利润；组件制造不是电站运营 |
| 电网、储能与调节 | 输配服务、价差或合格系统服务收入 | 项目具备技术能力不等于已取得收费资格 |

口径：千瓦是功率或容量，千瓦时是电量。装机容量不能直接与发电量占比比较；不同收入项目也不能重复相加。

电力系统同时需要“全年有足够电量”和“特定时间、地点有足够可靠出力”。风光可以增加低边际成本电量，却不能仅按名义装机等比例替代高峰可靠容量。煤电、水库、储能和需求响应的系统作用也不同。因此，转型不是传统能源明天消失，也不是所有承担保供的资产都能获得高回报。

本报告以中国上市公司投资研究为目的，重点覆盖煤炭与发电运营。油气、输配电设备、储能制造只列为关联研究入口，不宣称完成同等深度核验；尤其不把油价、动力煤、焦煤和天然气归入一个统一周期。

## 二、供需：用电增长仍在，利润分配却在改变

两套统计口径分别观察，不拼成错误的供需缺口

| 指标 | 2026年1—8月 | 如何使用 |
| --- | --- | --- |
| 全社会用电量[S1] | 71,730亿千瓦时；+4.3% | 覆盖全社会消费，用于需求趋势 |
| 规模以上工业发电量[S2] | 66,476亿千瓦时；+2.4% | 用于对应统计范围的生产趋势 |
| 其中火电 / 水电[S2] | 42,170 / 9,027亿千瓦时 | 同比+0.9% / +7.8% |
| 其中核电 / 风电 / 太阳能[S2] | 3,271 / 7,196 / 4,811亿千瓦时 | 同比+1.6% / +0.5% / +10.6% |
| 规模以上原煤产量[S2] | 306,443万吨；−3.3% | 约30.64亿吨，非可立即使用的入炉煤 |

口径：消费与规模以上发电的覆盖不同，不能相减得出全国缺电量；分项与总量存在四舍五入。分布式、统计范围与电源结构会影响比较，不能只用这一张表推断弃风弃光。

国家能源局同时披露，前八个月互联网数据服务用电695亿千瓦时、增长42.5%[S1]。按同表计算约占全社会用电0.97%。这说明新需求增长很快，但基数仍小；互联网数据服务也不全是AI。应把数据中心的区域负荷、接入与购电方式具体化，而不是用“AI耗电”给全国所有煤企和电站统一加增长率。

同比增长不回答电价问题。若新能源供给在某区域的特定时段集中增加，平均需求增长与午间价格承压可以同时发生；若输电、储能和用电时间匹配不足，富余电量与高峰紧张也能共存。投资研究需要省份、时段、合同和项目四个层次，而不是只看全国年度装机。

原煤产量下降也不直接证明现货涨价。进口、煤质、库存、运输和下游消耗共同决定可用供给。本报告没有完成10月1日各煤种现货、各省电价和全行业库存的统一取数，不给未经核验的“最新吨煤利润”。

## 三、煤炭：资源优势要通过成本、交付与资本纪律兑现

动力煤、焦煤和综合能源集团，分开研究

动力煤主要与燃料需求相关，焦煤还需结合钢铁和焦化；煤质、热值、硫分、洗选率与交货地点不同，报价不可直接横比。低成本矿山在价格下降时可能保持现金，但这不意味着其利润完全不受周期影响。高利润年份的低PE，往往恰好把峰值当成常态。

| 关键问题 | 需要核验 | 容易误判 |
| --- | --- | --- |
| 资源与安全 | 可采计划、采掘接续、审批、安全与环保投入 | 用总储量乘现价当企业价值 |
| 吨煤盈利 | 自产实现价与完全成本，分矿区和煤质 | 混入低毛利贸易煤，收入增长当产量成长 |
| 合同与物流 | 长协与市场煤结构、铁路港口和到厂净价 | 现货涨幅等比例套全部销量 |
| 资本分配 | 接续、矿权、并购、债务和分红现金桥 | 经营现金全部可分；维护支出永久为零 |

口径：开采权寿命和资源接续要进入模型；新能源替代、保供要求和安全停产可以同时影响煤企。

中国神华是煤、电、运输等综合业务，不宜当作纯煤矿。其2026H1中国会计准则归母利润287.15亿元；国际准则口径不同，且同一控制下合并改变比较范围[S6]。跨期研究需先桥接合并范围，不能把未重述历史利润直接拿来算增长。

陕西煤业中报收入788.95亿元，其中自产煤483.95亿元、贸易煤223.25亿元、电力68.15亿元[S7]。这个结构本身就提示：交易型收入不等于矿山经济收益。煤企分析应优先看自产吨成本、资源寿命和归属现金，而非简单按营业收入给规模溢价。

陕西煤业与陕西能源是不同上市主体。前者研究资源开采及相关业务，后者还需要拆煤电联营的燃料、电价和建设现金。兖矿能源、山西焦煤等可作为延伸对象，但须另行核验海外权益、煤种和成本，不能照搬神华或陕煤的利润率。

## 四、火电：核心是价差，不是单押煤价

电量、电价、燃料与容量收入分别建模

简化经营关系是：上网电量乘以电价与单位燃料、变动成本的差，再加适用容量、供热和辅助服务收入，减固定运行、折旧、融资等成本。煤价下降有帮助，但如果实现电价和利用小时一起下降，净结果仍可能恶化。高效率机组、长协煤保障与省份电价结构，比笼统“火电反转”更有解释力。

华能国际2026H1归母利润65.86亿元，同比下降28.89%；公司将变动归因为境内上网电量、电价和燃料成本下降的综合影响[S8]。这是现成的反例：燃料变便宜，不足以自动推出股东利润增长。本报告不把公司的归因进一步冒充已完成的逐因素量化分解。

### 容量电价有价值，但不等于无风险年金

2023年煤电两部制政策以330元/千瓦·年为固定成本测算参考，并区分合格公用煤电等适用条件[S3]。2026年完善机制要求煤电固定成本回收比例不低于50%，同时推动可靠容量补偿和其他调节资源机制[S4]。具体省份标准、考核、资格和结算决定实际收入，不能所有机组直接乘统一价格。

| 独立演算假设 | 计算 | 意义与边界 |
| --- | --- | --- |
| 100亿千瓦时上网量，电价下降0.01元/千瓦时 | 收入减少1亿元 | 税前简单敏感性，不是某家公司的预测 |
| 实物入炉耗煤0.4千克/千瓦时，煤价上涨100元/吨 | 燃料增加0.04元/千瓦时 | 需实物煤耗与同煤质煤价配对；不是标准煤耗 |
| 合格100万千瓦，按165元/千瓦·年作示例 | 名义容量收入1.65亿元/年 | 330×50%的政策示例，不是核实的省级实收，更不是净利润 |

口径：假设为展示单位关系。实际计算须处理热值、税价、厂用电、供热分摊、合同、机组可用性与考核，不能直接复制到个股估值。

机组向调峰转变可能减少电量、增加启停和维护成本。应观察固定成本补偿是否足够覆盖这些变化，而非同时假设传统高利用小时和全部新补偿收入。华润电力、华能蒙电、陕西能源等又有不同区域、资源和新能源组合，必须逐公司拆分。

## 五、水电：成熟资产的现金优势，仍有水文与再投资约束

经营韧性来自资产条件，不来自“公用事业”标签

成熟水库资产通常不承担煤价风险，长运行寿命、低燃料支出和调节能力有助于现金回收。但来水、库容调度、弃水、市场化电价、送出条件及生态要求共同决定收入。丰水年不能乘二变正常年，枯水年也不能被永久抹去。梯级协同与区域差异需要工程和水文证据支持。

长江电力2026H1归母利润147.56亿元，合并经营现金241.28亿元、购建现金44.35亿元[S9]。这提供成熟资产的现金观察窗口，却不能把现金差额全部当普通股分红能力：债务、利息、其他投资与少数权益仍待桥接，半年又不能简单年化。

- 长江电力：观察梯级运行、来水、实现电价、债务与资本分配。
- 国投电力：拆水电、火电及其他业务，不以集团装机冒充全部优质水电。
- 川投能源：联营权益与收到的投资分红，要和被投资公司的合并经营现金区分。

资产成熟和公司成熟不是同一回事。新工程建设、收购或扩张可以重新提高资金需求；电价市场化也可能影响水电收益。估值宜用多水文情景、完整维护投入和权益现金，而非只给“稀缺资产”套永续溢价。

## 六、核电：长期可靠出力，前提是穿越建设融资期

运营机组与建设机组，使用不同现金曲线

核电研究必须分运行、建设、已核准未建三个阶段。运行机组受大修、可用率、电价和燃料管理影响；建设机组先占现金，再逐步贡献电量。核准数量不是当年利润，工程延迟、资本化利息、合资权益和资金成本都会改变普通股结果。安全和合规是基本边界，不是可以用估值折价随意弥补的普通经营变量。

中国核电2026H1合并经营现金191.77亿元，购建现金346.03亿元，简单差额约−154.26亿元[S10]。购建包括集团不同业务，不等于全部核电建设。扩张使这一差额为负，不直接说明项目坏；但它说明新增项目需要融资和兑现回报，不能一面忽略建设现金，一面把未来增长完整计入价值。

合并利润也不都属于普通股。中国核电H1归母利润约36.41亿元[S10]；对中国广核等其他主体应重新核验合资比例、项目债务和建设计划，不能按运营千瓦照搬归母利润。长期模型还需显式考虑检修、延寿和最终退役等责任，不能默认折旧结束后成本也归零。

判断“成长是否创造价值”，应看新增投资在保守电价、利用率和融资条件下能否获得超过资本成本的权益现金回报；不是单看装机增速。股息与扩张的取舍必须有资金来源，不能把尚未形成的电量拿来支持当前分红。

## 七、风光与储能：从装机增长转向实现价格与现金回收

新能源电价市场化改变收入结构，不能用旧固定电价外推全部新增

2025年新能源上网电价改革推动风电、太阳能电量进入市场，并对纳入机制的电量进行差价结算；存量与2025年6月1日起新增项目分开安排[S5]。机制价格、期限和电量范围依规则及地方落实确定，市场均价高于或低于机制价格对应双向结算，不是所有电量永久享有单向保底。

| 项目经济性 | 重点证据 | 不能默认 |
| --- | --- | --- |
| 有效电量 | 资源、可用率、限电、并网和送出 | 名义装机×固定小时永不变 |
| 捕获价格 | 项目所在时段与区域的实际成交、合同和结算 | 全年平均电价代表午间光伏电价 |
| 机制收入 | 资格、适用电量、期限和差额方向 | 全部电量、整个寿命统一最低电价 |
| 绿色权益 | 绿证等归属、适用规则与实际成交 | 同一绿色价值重复加到电价和证书 |
| 储能 | 价差、调度、考核、损耗、寿命及合格补偿 | 政策认可技术就等于已获得稳定收费 |

口径：政策框架不等于每个省份、每个项目当前执行细节已全部核验；新增模型必须查地方条款和实际合同。

设备价格降低可以改善新项目投资额，却也可能吸引更多供给并压低特定时段电价。低建设成本、并网优先和好资源必须联合考虑。三峡能源、龙源电力及综合能源集团的风光项目，需检查权益装机、补贴应收、建设现金、地方交易结构和债务，不能直接套成熟水电的现金回收比例。

储能不是免费解决弃电。充放电损耗、循环衰减、调度限制、价差缩小和融资都影响收益。2026年容量机制涉及符合条件的电网侧独立储能等安排[S4]，项目应先证明适用与可得收入。设备制造利润又取决于订单、售价与技术竞争，不等同于运营端收益。

## 八、代表企业：按资产与现金机制分组

研究地图，而非未核现价的推荐名单

| 企业 | 研究角色 | 最优先核验 |
| --- | --- | --- |
| 中国神华 / 陕西煤业 | 资源与综合能源 / 以煤炭为核心 | 自产成本、合并范围、权益和分配 |
| 兖矿能源 / 山西焦煤 | 跨区域资源 / 焦煤相关 | 煤种、海外权益、钢铁需求与完整成本 |
| 华能国际 / 华润电力 | 综合发电运营 | 实现电价、燃料与资本支出；分业务拆开 |
| 华能蒙电 / 陕西能源 | 区域电力及资源关联 | 当地交易、煤电联营边界、建设与债务 |
| 长江电力 / 国投电力 / 川投能源 | 水电及不同集团权益结构 | 水文、联营分红、其他业务与融资 |
| 中国核电 / 中国广核 | 核电运营与在建项目 | 检修、电价、建设现金与少数股东 |
| 三峡能源 / 龙源电力 | 风光运营 | 捕获电价、限电、机制资格与应收回款 |

口径：仅对下文列明财务及原文来源进行量化核验；其他企业为尽调入口，不声称已完成其全部2026H1财务、现价与估值研究。

同一家集团内部也能出现资源盈利、电量盈利和建设现金相反的变化。比较时先把业务拆到统一定义，再回到归母每股价值。A股与H股若对应同一经营主体，业务现金基础可相通，但股价、币种、税费和权益工具须分别处理；不能把不同价格来源的股息率直接相减。

## 九、用现金流拆穿“都是高分红资产”的错觉

同为能源运营，资金曲线并不相同

| 2026H1；亿元人民币 | 长江电力[S9] | 华能国际[S8] | 中国核电[S10] |
| --- | --- | --- | --- |
| 营业收入 | 379.29 | 1,069.09 | 383.98 |
| 归母净利润 | 147.56 | 65.86 | 36.41 |
| 合并经营现金净额 | 241.28 | 252.43 | 191.77 |
| 购建长期资产现金支出 | 44.35 | 203.90 | 346.03 |
| 经营现金减购建现金 | 196.94 | 48.52 | −154.26 |

口径：源于公司中国会计准则中报；差额从原始元数演算后四舍五入，不是股东自由现金。购建口径未拆维护与扩张；合并现金含少数权益，未扣完整融资与其他投资，不能当可分红上限或直接年化。

这张表展示现金曲线，不排名好坏。成熟资产可能更早释放现金；成长公司可能用当前现金建设未来资产；火电在燃料和电价变化中形成另一种现金节奏。只有把项目收益、偿债和权益归属接起来，才能判断扩张是在创造价值还是消耗股东资本。

1. 由业务经营出发，核对经营现金与营运资金、税款、检修及季节性。
2. 把购建、并购、投资与收到的分红分别列示，维护与扩张尽量桥接；不能把预算和现金支付混比。
3. 列债务到期、利息、永续工具、受限资金和少数股东权利。
4. 核对母公司收到现金与可分配利润，最终落到普通股每股现金。
5. 压力情景允许电价下降、成本上升、工程延迟、融资收紧和股息下降同时发生。

折旧是历史成本分摊，不等于当期维护现金；经营现金高也不表示资本需求低。核电、矿山和大型水利资产的生命周期不同，必须具体判断更新投入。永续债会改变普通股收益与现金权利，不可只看会计上被列入权益就忽略其支付义务。

## 十、估值与情景：把不确定性放进现金流，而非统一折现率

行业优势不自动形成现价买入结论

### 资源价格走弱，电价相对稳定

- 煤企自产利润承压，低成本和物流优势更重要
- 火电可能受益于燃料下降，但需看电量与固定支出
- 煤电联营存在自然对冲，不等于完整无风险

### 煤价与电价一起下降

- 煤企与火电可以同时承压，不存在必然跷跷板
- 水电、核电和风光也可能受实现电价下降影响
- 融资和扩张压力使高分红假设需要重审

### 高峰保供与可靠容量价值增加

- 合格调节资产可能获得更匹配的收入结构
- 先核实际资格、考核、价格与成本，不直接资本化政策目标
- 需要区分电量收入变化和系统服务增量，防止重复计入

| 资产类型 | 合理估值约束 | 主要陷阱 |
| --- | --- | --- |
| 煤矿 | 正常煤价、可采寿命、完整成本与接续投入 | 峰值利润低PE；储量乘现价 |
| 火电 | 电量、电价、燃料、合格容量收入及改造支出 | 煤价永降；新收入与旧高利用率同时满额 |
| 水电 | 多水文、电价、维护、债务与权利期限 | 丰水永续；现金差额全部归母 |
| 核电 | 运营与在建分期、融资、权益、延寿及退役 | 核准直接变利润；建设和稀释不入模型 |
| 风光与储能 | 项目现金、捕获价、机制期限、寿命与再投资 | 新增装机全享历史电价；补偿永久确定 |

口径：不给全行业统一增长率、折现率或退出PE；本报告未更新个股行情，不提供未经现价核验的买入评分。

折现率应随现金稳定性、负债、工程与权利风险变化，但不能替代显式建模。矿山耗竭、核电建设延迟、风光机制到期和水文波动，应进入对应年度的现金路径。增加两个百分点折现率，并不能弥补把现金算错或把寿命当无限。

分红收益率是结果，不是保底承诺。高股息如果来自周期峰值、压低维护或新增负债，需要折价；低股息也可能是高回报再投资，但需证据。成熟低成本资产与建设型成长资产可以都值得研究，最终买入优先级仍由可验证现金和买入价格共同决定。

## 十一、后续验证：什么证据会改变判断？

关注现金机制，而不只刷新一条煤价

| 观察项 | 证据与节奏 | 改变判断的信号 |
| --- | --- | --- |
| 煤炭平衡 | 同煤质价格、自产成本、库存、贸易和运输；月度 | 资源优势无法抵销价格下降；交付或安全受限 |
| 电力交易 | 省份成交、合同、捕获价与结算；月度 | 量增价降，市场收入不足支撑原假设 |
| 可靠容量 | 地方细则、合格资格、可用性与实收；事件触发 | 政策名义收入与实际结算长期背离 |
| 水文与检修 | 来水、调度、机组状态；月度 | 一次丰水或低检修被误当长期能力 |
| 风光消纳 | 限电、送出、时段价格与机制电量；月度 | 装机增长却没有足够新增权益现金 |
| 资本与融资 | 项目进度、购建、到期债务、永续和少数权益；季度/半年 | 扩张回报弱、资金缺口扩大或普通股被稀释 |
| 分配可行性 | 母公司现金、可分利润、约束与实际支付；披露期 | 高股息由短期举债或压缩必需投入维持 |

口径：保留原公告日期、期间、单位与归属；缺数据不填零，未经桥接的数据不拼连续趋势。

### 最终判断

能源行业最重要的长期变化，是可靠供给与低碳电量并行，而利润越来越取决于资源成本、实现电价、系统作用与资本分配。煤企不能只靠高煤价，火电不能只靠低煤价，水电不能只靠丰水，核电不能只靠核准，风光不能只靠装机。真正值得长期持有的公司，要能在完整生命周期和权益约束后持续创造普通股现金；真正有吸引力的投资，还需要买入价给这些不确定性留下余地。
