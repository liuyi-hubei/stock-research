# 广告与游戏行业

分众传媒、三七互娱；研究固定触达网络与产品运营的不同经济性

研究日期与口径：2026-10-01

作者：刘益的复利研究室 · 独立行业研究

## 高毛利不等于高回报，注意力必须转化为可持续现金

分众卖的是特定场景触达，三七互娱卖的是游戏体验与持续运营，两者都参与注意力竞争，却不能用同一个盈利模板。2026H1分众归母31.28亿元、扣非22.91亿元；三七归母17.66亿元、扣非10.16亿元，均存在明显口径差异。前者要扣除点位租赁现金再判断分配能力，后者要在买量、研发和产品衰减后评价回报。AI和并购可以带来机会，却不能替代客户复投、用户留存及资本配置证据。[S1][S2]

## 01｜注意力相同，赚钱机制不同

不能把“传媒”当成统一的估值行业。

广告主购买的是触达目标人群、促进认知或转化的机会。游戏玩家购买的是内容体验、社交互动或虚拟服务。两者都争夺时间和预算，但广告网络的成本取决于点位与销售组织，游戏公司的成本更多来自研发、渠道、投放和运营。相同的毛利率可能对应完全不同的维护投入和盈利波动。

| 维度 | 楼宇广告 | 游戏研发与发行 |
| --- | --- | --- |
| 付费者 | 广告客户及其代理体系 | 玩家，部分收入受平台结算影响 |
| 重复收入来源 | 客户复投、持续场景覆盖 | 用户留存、持续更新和新产品 |
| 关键现金投入 | 点位租赁、设备、销售及回款 | 研发、买量、平台费用与运营 |
| 主要风险 | 预算迁移、空置、租金、客户效果 | 产品衰减、新品失败、渠道成本和监管 |

行业研究的重点是为什么付费者继续付款，以及维持这种付款需要持续投入多少。拥有屏幕和拥有游戏都不是永久护城河；如果客户效果下降或玩家流失，历史规模不会自动转成未来现金。

## 02｜广告增长要拆预算、份额与净价格

宏观改善不是所有媒介收入增长的充分条件。

广告预算来自客户对销量、品牌与获客回报的判断。消费和企业利润改善可能增加预算，但媒介之间竞争激烈，品牌广告与效果广告也不是固定比例。短视频、电商、搜索、线下和其他媒介各有用途；平台归因规则与客户投放周期改变，会影响预算分配。

楼宇场景的价值在于特定地点、频率和人群，不能简单用“强制观看”证明长期商业效果。有效触达需要去重、频次和目标人群质量；客户把预算持续交给某家公司，还需要产品、品牌建设与销量反馈。媒体自身报告的曝光与第三方效果可能口径不同，不应直接转换成收入或利润。

- 广告量：售出时段、城市与点位质量，不能只数屏幕数量。
- 净价：折扣、返利、代理费用、赠送时段与回款条件要合并评价。
- 客户：长期品牌、短周期促销、新客户与重复客户分开。
- 效果：复投与客户经济回报优先，未经核验不编造归因或ROI。

当客户缩减预算，固定点位租金并不会等比例下降，经营杠杆会放大利润波动。反过来，利用率提高时新增广告可能有较好边际贡献，但如果通过过低价格填充，规模增长不一定改善现金资本回报。

## 03｜广告网络的优势与固定成本是一体两面

集中覆盖需要密度，也需要租后现金。

密集点位、城市网络和销售组织能降低客户跨区域投放的协调成本，重复触达也可能提高品牌记忆。优势的检验是客户在有其他选择时是否愿意续投，以及公司在支付点位和销售成本后能否保留合理收益，而不是市场覆盖广就必然有定价权。

房东、物业和广告网络之间也存在议价。热门点位租金可能增长，低效点位又可能因为长期合同无法迅速退出。点位扩张应同时观察新增客户收入、维护现金与退出义务，不能只把屏幕增长写成未来收入增长。

| 候选优势 | 正向证据 | 反向证据 |
| --- | --- | --- |
| 网络密度 | 跨城市服务与客户复投提高 | 低效点位和重复覆盖拖累回报 |
| 销售能力 | 净价和回款质量稳定 | 返点与账期换取收入 |
| 数据与技术 | 测量改善并提升客户真实效果 | 展示能力增加但客户不愿继续付费 |
| 行业整合 | 单位成本与客户服务真实改善 | 高价并购、稀释与固定义务扩大 |

因此并购应按支付对价、融资、股数、整合现金与经营质量评价，不能只算合并收入或市场份额。审批、交割、股权登记与并表是不同事件；未取得完成证据的交易不提前计协同或新增利润。

## 04｜游戏真正的资产，是留存和产品能力

高毛利必须经得起买量与生命周期检验。

游戏毛利率通常没有完整表达获客和研发成本。发行公司可能在销售费用中投入大量推广，新产品先花钱再回收，老产品又会自然衰减。判断游戏经济性，要区分研发自有、代理发行、平台渠道和不同品类，而不是把所有流水当收入或把收入当用户净贡献。

用户终身贡献与获取成本是重要概念，但没有公司披露的留存、付费、渠道分成和回收数据时，不能填入精确LTV/CAC。公司可以通过降低投放改善短期利润，却使下一阶段收入下降；也可以通过增加买量短期扩大收入，却拉长现金回收。关键是产品和用户是否有可持续关系。

- 老产品：生命周期、更新内容和付费留存，不能假定永久稳定。
- 新品：取得许可或预约量不等于成功，上线、用户质量和回款要分段验证。
- 渠道：平台抽成、流量竞价、结算与规则变化，不能默认公司掌握全部利润。
- 研发：费用化与资本化分别看，设备资本支出低不等于维持业务没有再投资。

真正可重复的能力是持续产出玩家愿意留下和付费的产品，并以合理成本分发；一次爆款可以产生现金，却不必然证明整个团队拥有稳定产品成功率。估值应保留失败和衰减，而不是只把储备游戏按上线数量计利润。

## 05｜归母上升与主营改善不能画等号

人民币亿元，2026H1累计；同比采用原公告口径。

| 指标 | 分众传媒 | 三七互娱 |
| --- | --- | --- |
| 营业收入 | 59.91（−1.98%） | 72.75（−14.28%） |
| 归母净利润 | 31.28（+17.39%） | 17.66（+26.14%） |
| 扣非归母 | 22.91（−7.06%） | 10.16（−26.74%） |
| 归母减扣非 | 约8.38 | 约7.50 |
| 经营现金流净额 | 44.53（+30.91%） | 10.89（−37.89%） |

口径：来源[S1][S2]；差额是非经常损益归属后的净影响，不等同某一项税前投资收益。三七已核交易所原文，分众已核妙想公告全文片段。

两家公司当期归母增长而扣非下降，不应被概括为主营已经复苏。扣非也不是完美正常化利润：某些经济损失仍是真实资本代价，反复存在的补助或投资活动也有各自性质。应逐项查看处置、投资、公允价值与税的影响，再估计可持续现金。

现金方向也不同。分众的经营现金提高需要结合结算、租赁和点位投入；三七经营现金下降需要同时观察收入、产品与推广回收。行业报告不把半年数机械年化，不在原个股数据之外再制造一套收益率或评级。

## 06｜分众：租后回报与并购纪律优先

设备少不意味着固定现金义务少。

楼宇广告需要持续占用点位，使用权资产和租赁负债的会计呈现会让经营现金看起来强于实际租后可用现金。应把现金流表筹资分类中的租赁本息纳入分析，同时避免把同一租赁付款再以总租赁现金重复扣除。广告设备购建低，也不等于整个经营网络没有维护成本。

本次妙想返回原始公告核对分众购建现金492,259,248.49元、筹资租赁本息1,217,725,679.75元；结合经营现金4,453,428,032.40元，三者差额为27.4344亿元，仅为租后现金观察。[S1][S3] 不称全量重新阅读了租赁附注；子公司少数股东、母公司汇付、税与并购现金还要另核。

公司价值不能只由广告网络规模决定。预算迁移、广告客户回报、房东议价和低效扩张会改变盈利中枢。对于新潮等交易，本报告不声称截至研究日已完成交割，也不提前增加协同利润或每股收益；最终交易完成需重建利润归属、总股数、融资和现金义务。

- 上调依据：客户真实复投、净价与回款质量改善，租后现金和资本回报同步增强。
- 下调依据：收入依赖账期或返点、固定租金压缩利润、低回报并购扩大风险。
- 分红边界：历史高分配只证明过去选择，不能成为未来十年现金保证。
- 资本配置：金融投资回款和处置收益不应永久填充广告主业的资金缺口。

## 07｜三七：以扣非、产品与投放现金验证复苏

投资收益不能替代新旧游戏的经营表现。

三七2026H1归母17.66亿元与扣非10.16亿元差距明显，经营现金10.89亿元也低于上年同期。[S2] 不宜以报表利润上升直接判断游戏业务进入高增长阶段。应把投资损益与游戏经营分开，再分析旧产品衰减是否得到新品和运营质量补充。

发行能力和买量系统能够提高运营效率，但效果会受平台、竞品、地区与玩家变化影响。推广费用减少可能帮助当期利润，也可能减少后续用户；需要观察几个产品周期，不能只由一季费用率下降下结论。设备购建支出小，不代表新游戏与投放不需要持续资金。

研究单款产品要结合发行权益、流水到收入的确认、平台结算、研发与运营成本，并留出失败损失。由于公司未在本次证据中给出完整单品留存与获客成本，不为这些指标补精确数字；产品名单和预约排名只能作为跟踪线索。

- 主营判断：扣非与经营现金是否在多个期间同向改善，而非只有非经常收益提高。
- 现金判断：投放回收、新品预算、投资付款和分红是否相容。
- 产品判断：旧产品稳定性、新品贡献与海外运营的可重复性。
- 治理判断：商誉、股权投资、法律与披露风险要依原始公告持续核对，不能从一份中报推断全部事项无风险。

## 08｜AI与出海：先看成本和付费，不先加溢价

生产效率可能提高，也可能降低行业门槛。

AI可以帮助广告创意、客户分析、游戏素材和测试流程，但提升效率不等于企业拥有新的垄断收益。若工具对所有竞争者开放，节省的成本可能被竞争或客户议价拿走；内容供给增加也可能抬高用户筛选与推广成本。应观察净节约、质量、合规与客户效果，而非工具使用次数。

游戏出海需要本地文化、运营、许可、支付、数据和渠道能力。海外收入要区别本地产生、跨境发行与海外平台结算；汇兑、预扣税和现金汇回会影响普通股实际收益。某一产品或地区成功不能直接外推全球成功率。

| 机会 | 需要验证 | 不能提前计入 |
| --- | --- | --- |
| 广告创意自动化 | 时间成本下降且客户效果持续 | 未核的AI新增收入和溢价 |
| 游戏研发辅助 | 实际成本、质量与生产周期改善 | 所有研发费用可以削减 |
| 精准分发 | 用户净贡献高于投放成本 | 未经披露的精确获客回收率 |
| 海外运营 | 净结算、税与现金汇付 | 把海外流水全归属上市利润 |

版权、训练材料、内容安全与数据合规也有成本。技术采用应作为经营变量，不能成为跳过财务证据、提高长期增长和退出倍数的理由。本报告不声称已经确认AI对两家公司带来具体利润增厚。

## 09｜轻资产公司更需要资本配置研究

没有很多设备，也可能没有很多可分配现金。

广告与游戏的再投资常通过费用、租赁和运营资金发生，不完全在传统资本开支里。机械用经营现金减设备购建，会遗漏分众点位租赁，也可能低估游戏维持产品能力所需的研发与推广。行业比较必须先理解现金分类，再讨论自由现金。

1. 经营起点：区分主营、投资、处置和公允价值损益，不把归母全当重复现金。
2. 持续投入：广告网络租赁、维护、销售，游戏研发、投放和运营，分别核对。
3. 外部资本：少数权益、利息、债务、税及母公司收到现金，合并与母公司不重复加。
4. 资本配置：收购、金融投资和回购分开，确认价格、权益和潜在稀释。
5. 股东分配：在上述资金约束后估计可持续股息，不把已除息现金加进未来回报。

现金多并不自动说明管理层会以合理方式使用。高价收购和低回报投资可能损害原本良好的主业；另一方面，停止无效投放或退出低效点位也可能降低收入却增加价值。每股可分配现金比规模考核更适合投资判断。

## 10｜广告估租后现金，游戏估产品组合的重复性

不为AI、轻资产或高股息设置统一倍数。

| 估值环节 | 分众传媒 | 三七互娱 |
| --- | --- | --- |
| 正常化起点 | 广告主营利润与租后现金，剔除一次性回款 | 产品经营利润，分离投资和公允价值收益 |
| 近期增长 | 客户预算、净价与有效点位利用 | 旧产品衰减、新品贡献及投放效率 |
| 成熟状态 | 客户复投、租金与媒介替代 | 产品成功率、维护研发及渠道议价 |
| 风险门槛 | 固定成本、并购和客户效果 | 爆款不确定性、平台、许可及资本配置 |

悲观情景应包含广告预算减少但租金仍在，以及游戏老产品衰减而新品失败；基准不能靠每年出现爆款或一次性投资收益；乐观需要复投与留存改善的证据。分红与增长共同受现金约束，不能既假设高额留存驱动增长，又把全部利润派给股东。

终值不是今天的热度延续。第十年的成熟竞争、维护投入和产品能力决定退出估值，不能为了排名漂亮提高PE。未建立具体产品和资本预算前，宜用有限可信度情景描述，不给出无依据概率或确定价格。此处不改网站已有个股假设与排名。

## 11｜反向压力：什么会让高毛利失去意义

从真实现金义务识别风险。

| 风险 | 广告侧 | 游戏侧 |
| --- | --- | --- |
| 需求迁移 | 品牌预算转向其他媒介 | 玩家时间转向竞品与其他娱乐 |
| 固定或先行投入 | 点位租金与长期合同 | 研发、投放先于回收 |
| 规模错觉 | 低效屏幕、返点与延长账期 | 流水、注册量与低质量买量 |
| 资本配置 | 并购稀释与不重复处置收益 | 投资波动、商誉与产品收购 |
| 合规 | 广告内容、测量与数据 | 许可、内容、未成年保护与数据 |

这些风险应进入联合情景：收入下降时投入未必同步下降，投资资产也可能同向承压。高毛利不能防止现金流下降，账面现金也不能无限支持失败产品和低效点位。若出现持续资金缺口，应同时削减增长、派息和终值，而不是用AI故事补上估值。

## 12｜什么证据会改变判断

不以一季报表归母增长代替行业复苏。

- 分众客户复投、净价与实际效果改善，租后现金可覆盖维护和普通股分配。
- 新潮等交易最终完成、对价、融资、股数与经营归属的原始文件；完成前不计协同。
- 三七扣非和经营现金连续改善，同时确认投放效率和新旧产品的贡献。
- 产品留存、净结算与获客回收若获披露，再建可复核单品模型，未披露不猜数字。
- 金融投资、处置与商誉按性质分开，资本配置损失不能永远当“非经常”忽略。
- AI净节约、产品质量和付费结果，不能只统计技术使用或生成内容规模。

目前更合适的研究结论是分别跟踪两类商业模式的重复现金能力。分众具备网络服务的候选优势，三七具备产品运营的研究价值，但未来收益仍取决于客户与玩家、资本纪律及买入价格。行业报告不表示五位投资者本人持仓或意见，也不是新增买入推荐。
