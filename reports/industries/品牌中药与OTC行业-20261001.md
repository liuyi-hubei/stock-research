# 品牌中药与OTC行业研究

云南白药 · 华润江中

研究日期与口径：2026年10月1日；财务截至2026年6月30日

作者：刘益的复利研究室 · 独立研究

## 品牌可以降低选择成本，但不能绕过疗效、渠道与资本纪律

品牌中药与OTC值得长期研究，理由不是“中药永远增长”，而是成熟产品在明确适用场景下可能形成信任、重复购买和较低的新增资本需求。但品牌、独家批准与现金分红是不同层面的优势。云南白药收入横跨药品、健康品和医药商业，不能全体套品牌倍数；华润江中聚焦零售大单品，2026H1收入下降而现金改善，说明终端消费、渠道发货与回款并非同一件事。研究应从正常化主业利润出发，穿透投资收益、库存、营销、研发及母公司可分配现金，再判断价格是否留下安全边际。

## 一、产业地图：中药、OTC和健康消费品不是同一种生意

按实际产品与支付渠道拆分，不按板块标签统一估值

| 业务 | 需求与竞争 | 需要先回答的问题 |
| --- | --- | --- |
| 院外非处方药 | 消费者自行选择，药师、品牌、可获得性和价格共同影响购买 | 适用场景清楚吗，复购是否需要持续大量促销 |
| 院内与处方产品 | 临床证据、医生使用、准入和支付机制 | 销量、实际净价与合规成本如何变化 |
| 健康品与日化 | 消费选择、功效体验、渠道陈列与替代品 | 药品品牌能否真实转移到新品类 |
| 中药饮片与原料 | 产地、质量一致性、加工、供应与追溯 | 稳定质量和周转是否形成资本回报 |
| 医药商业与配送 | 供应链、回款、客户信用和规模效率 | 收入规模能否转化为现金和足够利润 |

口径：本表为独立商业分析分类，不是证券行业分类；OTC是用药管理属性，不等于全部为中药。

“中药”描述部分产品与工艺，“OTC”描述处方管理，“品牌”描述消费者和专业渠道的认知。三者有交集却不能互相替代。华润江中披露非处方药、处方药、健康消费品等不同业务；云南白药同时经营药品工业、健康品与医药商业。[S1][S2] 因而观察行业机会时，应先找到收入背后的实际客户、用途和竞争者，再讨论长期盈利。

同一集团的品牌产品可能具有较高毛利，商业配送却需要更多周转资金且利润率较低。集团收入增长可以来自两者占比变化，不必然意味着品牌提价或竞争力增强。研发、生产、营销、财务投资和分配又各有现金时序；用一个综合增长率和一个统一退出倍数，容易把结构变化误当成永久优势。

本报告研究两家项目已覆盖企业，并建立可复用行业框架，不声称两家公司代表全行业景气。没有在本轮取得所有药品终端销量、药材价格与完整零售样本，所以不将“行业见底”“全面复苏”写成已确认事实。

## 二、需求：常备场景能重复出现，但每次购买都存在替代

人口与健康需求，是研究起点而不是公司增长保证

家庭常备药的价值来自明确需求发生时的可获得性与信任。真正重要的是消费者能否理解适用场景、按规范使用并获得合理体验，而不是广告中覆盖了多少潜在人群。消费者可以减少购买、改规格、换品牌、咨询药师或使用其他方案；这些选择决定企业能保留多少溢价。长期需求存在，不等于特定单品每年增长。

| 需求场景 | 可能的经济特征 | 主要研究边界 |
| --- | --- | --- |
| 小伤口及运动相关护理 | 便携、渠道可得与品牌信任 | 具体产品资质、使用范围与竞争替代 |
| 脾胃及肠道需求 | 场景重复、品类认知与药师推荐 | 不能把不同成分和不同适用人群混作同品 |
| 咽喉及季节性需求 | 季节、流行病与渠道备货影响较强 | 避免将异常高销量基数永久化 |
| 口腔护理及健康消费 | 使用频次较高但替代丰富 | 药品声誉不等于日化无限提价能力 |
| 基层与慢病相关用药 | 用药需求与准入、支付相互作用 | 需求人数不能直接推算收入或利润 |

口径：这是投资研究的场景划分，不提供个人用药建议；适应症及宣传以具体批准与说明书为准。

销量应按同品、同包装、同渠道观察。大包装增长可能来自零售采购改变，小包装提价又可能掩盖总用量下滑；疫情、流感或其他短期需求高峰之后，不能用最低谷同比恢复证明结构性扩张。若需要建立长期增长路径，至少应区分真实消费量、终端价格、产品组合和公司份额。

老龄化可以提高某些医疗与护理需求，但支付能力、购买频率、替代方案与监管适用会限制可实现的收入。品牌中药研究不应从宏观人口数直接推导某一公司的十年复利。更有用的是检验一个产品能否为具体用户持续提供价值，以及维护该价值需要多少新增费用与资本。

## 三、护城河：独家品种、品牌和质量体系需要分别验证

品牌不是宣传费用少，独家也不代表没有替代

独家品种可以降低完全同配方竞争，但消费者解决问题的方式可能很多。处方或非处方管理、产品批准、剂型、适用范围和商标保护各自形成不同边界。研究者应看替代方案的总成本与使用便利，而不是仅因“独家”二字就假设永久定价权。批准文件和品牌知名度都不是临床效果的比较证明。

| 优势来源 | 如果真实成立，应看到 | 可能失效的情形 |
| --- | --- | --- |
| 消费者信任 | 合理促销后价格与复购仍稳定 | 低价替代、负面质量事件或体验变差 |
| 专业渠道认可 | 药师与终端愿意持续陈列和推荐 | 推荐依赖短期返利，渠道利润被压缩 |
| 质量与供应 | 批次一致、可追溯、可靠交付 | 原料不稳定、合规成本被低估 |
| 规模与组织 | 费用与供给效率随覆盖提高 | 新品与子品牌越多，管理复杂度越高 |
| 品类认知 | 消费者自然把需求与品牌关联 | 认知老化，购买入口迁移后优势削弱 |

口径：属于可证伪的研究标准，不是已经完成消费者调查或产品临床比较。

品牌维护费用不能被简单视为浪费：稳定的质量、必要推广和售后是在维护生意。真正需要警惕的是费用效率恶化——广告投入增长快于有效消费，停止投入后销量骤降，或者新品长期靠返利维持渠道库存。反过来，销售费用下降也未必是利好，可能伴随失去触达或品牌投资不足。

长期优势应由价格、销量、费用、资本回报和现金共同支持。单一排行榜、公司引用第三方的份额数据或商标荣誉，可以帮助定位产品，但不能独立证明护城河扩大。本报告不把企业自述“领先”改写为本次独立市场调查结论。

## 四、渠道：给渠道留下利润，才能把发货变成持续消费

经销、连锁药店、电商与医院，观察方法各不相同

厂家收到订单，渠道收到货，消费者实际使用，是三个不同阶段。预收改善可能意味着渠道愿意备货，也可能只是季节或促销付款变化；经销商库存下降可能健康，也可能因为产品失去吸引力。渠道判断必须把终端销售、价盘、退货、应收、账期与补货意愿放在一起。只看集团收入或经营现金，不能推断所有产品动销。

| 渠道 | 形成优势的条件 | 需要穿透的费用和资金 |
| --- | --- | --- |
| 连锁药店 | 可得性、药事服务、合理渠道利润 | 进场、陈列、促销、返利和结算账期 |
| 传统经销 | 覆盖效率与终端管理 | 库存、窜货、应收和退换货 |
| 平台电商与即时零售 | 便利、搜索认知与真实复购 | 佣金、投流、配送、价格差和退款 |
| 医院与基层机构 | 临床价值、准入与合规服务 | 实际净价、回款、招采与推广成本 |
| 商超与其他消费渠道 | 与健康品或日化场景匹配 | 货架、物流、促销及不同用户预期 |

口径：各公司的合同、收款与收入确认以实际披露为准；不预设所有渠道都适用同一周转规则。

线上销售可以减少部分中间环节，却增加获客、平台服务与低价比较压力。线上增长并不自动提高净利润，也不说明品牌可跳过药事服务与合规责任。应把消费者实际支付价与厂家净收入分开，按同品观察促销强度和渠道间价差，而不是只比较平台成交总额。

渠道良性通常表现为终端愿意售卖、消费者愿意重复购买、经销库存不过量、厂家回款正常。若长期利润来自提前压货、挤压渠道或延长供应商付款，现金漂亮也可能缺乏持续性。下一轮研究最有价值的补证不是再加一份宏观叙事，而是可比终端样本和分产品渠道变化。

## 五、政策与质量：支持产业不等于保证产品价格

院外品牌、医保支付与集采必须按具体产品核查

2025年国务院办公厅关于提升中药质量的意见，强调资源、规范生产、创新和质量监管等要求。[S3] 对投资研究的启示是，长期经营不能只依赖品牌故事：原料、生产、检验、追溯和持续合规都需要真实投入。政策支持可能提高规范企业的相对优势，也可能先增加成本；不是单向的利润补贴。

医保、基本药物配备和集采影响不同的准入与支付环节，不能将“中成药”视为统一受益或统一免疫。OTC身份也不是天然不受价格、准入和支付变化影响。应逐品种核对是否进入相关采购、区域规则、执行日期、净价、用量、渠道变化和费用调整，之后再分析集团利润。未核清产品名单时，不量化假定统一降价幅度。

| 政策或合规变化 | 研究问题 | 不能直接得出的结论 |
| --- | --- | --- |
| 质量与追溯要求提高 | 新增成本多少，原有体系能否适应 | 龙头利润必然增加 |
| 带量采购与价格规则 | 实际产品、净价、执行区域与份额 | 中选即利润增长，未中选即退出市场 |
| 基层用药与渠道调整 | 需求、配备与付款如何落实 | 政策文本已变成公司订单 |
| 药品与消费品宣传监管 | 批准范围、宣传和渠道行为是否合规 | 品牌知名度可替代科学证据 |
| 药店结构与线上迁移 | 议价、服务与获客成本如何变化 | 减少中间层必然增加厂家现金 |

口径：政策框架不替代法律意见；本轮未完成所有地方招采及新规则逐项法律核查。

投资者还应区分生产质量、临床价值和宣传表达。能够规范生产并不自动证明某产品优于全部替代方案；批准适用范围也不意味着可扩展到所有健康需求。本报告仅研究商业机制，不对药效作未经验证的医学判断，更不把行业宣传中的健康收益计作可直接估值的资产。

## 六、原料与供给：质量稳定比赌药材价格更重要

采购、种植、库存与生产投入，构成共同约束

中药材价格受到种植周期、气候、产地、质量等级、库存和供需变化影响；同一种名称不同产地和等级未必可替代。采购成本下降可以改善毛利，但若原料质量、供应稳定或终端售价同时变化，利润结果仍需重新判断。公司买入大量药材也不是无风险“锁定低价”，还要承担库存占款、损耗与质量责任。

向上游种植或加工延伸，可能强化追溯和供应，却把更长的周期与固定投入带入原本较轻的品牌生意。供应链一体化只有在减少质量风险、改善综合现金或提高资本回报时才有意义。不能因“全产业链”标签就给更高倍数，而忽略新增土地、设备、存货与经营管理。

| 观察项目 | 需要配对的数据 | 可能的误读 |
| --- | --- | --- |
| 原料采购改善 | 同质量采购价、耗用量、终端净价 | 药材降价全部变成利润 |
| 库存增加 | 库龄、质量、备货与预计消费 | 原料储备越多越安全 |
| 自建生产或原料基地 | 投资、利用率、质量与总成本 | 投产即满产，投入只是一次性 |
| 供应商结算 | 信用期、票据与采购稳定 | 延长付款产生永久现金 |
| 新品生产规模 | 真实需求、合格率和持续费用 | 收入不大但产能大，必然高增长 |

口径：本轮未取得完整药材连续价格与逐品库存，因此只给验证路径，不声称当前成本已处历史底部。

原料周期与库存周期还会造成利润和现金错位。存货先在低价采购、后在高价销售，可能产生阶段性毛利；高价库存消化则拖累后期表现。正常化研究应穿过完整采购与销售周期，避免用某半年低成本、高毛利推断十年盈利。产品质量成本始终先于利润优化。

口径：来源[S1][S2]；原值精确到人民币元，网页四舍五入。观察差额是本报告计算，不是归母自由现金流或可分红上限；半年数据不直接年化。

云南白药收入与扣非盈利小幅增长；华润江中收入和盈利下降，但经营现金增加。这足以说明收入、盈利和回款需要独立研究，却不足以仅凭两家公司判断行业景气拐点。经营现金还受到期初应收、采购付款、库存与合同负债影响，需结合完整年度和分产品终端证据。

主要会计数据采用合并口径。母公司经营现金、收到子公司股利和集团现金不能再次相加；收到理财赎回本金不是销售收入，投资支付也不能全称生产资本支出。两份中报的现金表给出了不同用途的分类，应依用途判断，而非简单把全部投资现金流出扣减一次再把回收款加为经营收益。

这些表格是事实锚，不是更新个股模型的指令。本轮没有修改云南白药、华润江中的股价、研究参数、五位视角或排名。若后续更新个股估值，仍须重新核行情日、股本、除息、利润正常化与分配约束，不能直接把本表利润乘二。

## 八、公司差异：一个看业务组合，一个看大单品质量

用不同问题研究云南白药与华润江中

云南白药的关键不是整个集团收入有多大，而是药品和健康品的产品竞争力、商业业务的周转与资本配置能否协调。药品声誉向牙膏等健康品延伸，需要消费者体验与复购支持；商业收入则不能使用完全相同的品牌估值。跨产品与跨业务的研究，必须先看利润来源和完整资金需求，不能用某一明星产品解释全体集团收入。

华润江中的研究重心更靠近零售大单品、专业品类和渠道经营。收入下降时，应进一步区分终端需求、渠道库存、价格、产品组合与执行；利润降幅较小，也不必然说明需求已经稳定。成熟产品可以贡献现金，新品与处方业务却可能需要不同的营销、研发和回款安排。把两者统一设为品牌永续增长，会遮蔽真实经营责任。

| 公司 | 最有价值的研究问题 | 主要反证 |
| --- | --- | --- |
| 云南白药 | 工业、健康品和商业分别创造多少正常化权益现金；新投资是否克制 | 品牌现金被低回报项目吸收，商业占款增加或主品竞争变差 |
| 华润江中 | 成熟单品真实动销与渠道盈利；新品投入是否形成稳定回报 | 销量依赖压货促销，渠道价盘恶化或新品长期亏损 |
| 两者共同 | 长期分红是否来自经营现金而非存量储备消耗 | 连续分配高于持续经营现金，资产处置或借款补缺 |

口径：公司判断是独立框架推演，不表示任何投资大师本人对两家公司当前的持仓或意见。

对两家公司都不应把“有现金”当作管理层一定会合理使用的保证。现金越充足，资本纪律越重要：未来投资、并购、研发和特殊分配，需要逐项考察用途、回收、风险和每股影响。品牌生意本身优质，与公司整体资本配置优质，是两项独立判断。

## 九、分红：从经营能力桥接到普通股能够收到的现金

高派息历史是参考，不是永久承诺

合并经营现金减购建支付，是观察资产投入后现金的起点，不是普通股股东可直接分配金额。还要核对维护与扩张是否已充分发生、租赁、债务、少数股东、母公司法律利润、资金归属和未来承诺。经营现金已扣费用性研发和营销时，不能再全额重复扣除；资本化研发、设备或项目付款则需要从相应资产与现金分类核查。

| 桥接环节 | 研究动作 | 典型风险 |
| --- | --- | --- |
| 利润到经营现金 | 拆非经常性、库存、应收与付款时点 | 盈利增长来自非持续收益 |
| 经营现金到资产投入后现金 | 分清生产购建、租赁、并购、维护与扩张 | 把当期低资本支付视为永久轻资产 |
| 集团到母公司 | 核子公司上缴与法律利润、受限资金 | 集团现金在其他主体而不可随意汇出 |
| 母公司到股东 | 核董事会决议、除息日与实际义务 | 把历史股息再次计入未来 |
| 分配到未来竞争力 | 保留合理研发、质量、周转与债务缓冲 | 为了高派息削弱长期业务 |

口径：各环节需要具体金额与时间；不能把同一笔子公司现金或投资收益重复计算。

高派息可减少低效留存，但若长期经营现金不足以支撑分配，历史储备只能暂时弥补，无法创造永久年金。特别股息释放的是已有权益，不应在估值中既保留同一现金资产，又再加一次额外股息。若只是观察股息率，还必须核除息与当前买入后能否取得权利。

稳健情景不是把分红率统一调低，也不是将最近一次高派息永久化，而是让每一年的分配与当年的经营、研发、质量、周转和债务责任相容。增长较低的成熟产品可能分配更多；需要新资本的业务则可能留存更多。关键是每股现金是否合理，而不是行业共同的固定派息比例。

## 十、创新与资本配置：成熟现金流不应替新项目掩盖风险

老产品再开发、创新药与并购分层研究

对成熟品牌做剂型、配方体验、生产质量和适用场景改进，可能提高产品价值；进入创新药或新技术领域则面对更长的验证周期和不同失败风险。公司有能力投入，不等于项目经济回报已成立。应将现有业务价值与未来项目期权分开，不把临床阶段、受理或技术合作直接变成确定的利润增长。

| 投入类型 | 可验证的进展 | 仍缺什么 |
| --- | --- | --- |
| 成熟产品再开发 | 合规批准、真实销量与费用效率 | 改善体验是否转为可持续现金 |
| 新消费品类 | 试用转复购、渠道毛利和经营利润 | 是否只是借老品牌购买一次 |
| 创新药或长期研发 | 阶段里程碑、质量与试验进展 | 成功概率、商业支付与后续资本需求 |
| 并购整合 | 实际权益、价格与现金回收 | 协同是否兑现，少数权益和商誉风险 |
| 金融资产配置 | 收益、风险、流动性与归属 | 是否偏离主业，是否影响核心资本安排 |

口径：本轮不提供未经核验的临床成功率、管线销售预测或并购协同估值。

治理分析应关注管理层如何选择不做的事情。若品牌主业资本回报较高，却把大量现金投入不熟悉的低回报领域，股东可能同时损失现金和组织专注。相反，必要的高质量研发不能因短期利润而全部取消。比较应基于投入的客户价值与现金回报，而不是“研发越多越先进”或“费用越少越好”。

研究基准可以只计已经可理解的成熟业务，让新项目在结果与成本更明确后更新；这不是认定创新价值为零，而是避免在证据薄弱时预先支付全部乐观收益。若给项目独立情景，要保留失败、延迟和继续融资的成本，并明确不与成熟业务增长重复计算。

## 十一、估值：正常化权益现金，比“老字号低PE”更重要

不同资本责任，对应不同增长、分配与退出假设

估值首先回答哪些利润能持续。不能仅用扣非标签认定所有剩余收益均来自品牌主业，也不能不分税和权益将投资、减值或特殊项目全额加回归母。应从业务和现金解释正常化盈利，再使用完整股权口径；若单列净现金，必须同步处理相关收益、债务、归属和释放时点，避免重复。

| 研究状态 | 需要的业务证据 | 对情景的影响 |
| --- | --- | --- |
| 成熟稳定 | 同品动销、合理价格、必要费用和现金持续 | 低增长、可验证分配与成熟退出 |
| 经营修复 | 终端与渠道库存改善，不只是低基数同比 | 利润逐步恢复，不能一步跳回历史峰值 |
| 新产品成长 | 复购、正贡献利润和合理新增资本回报 | 增长与留存共同设置，不把铺货当终点 |
| 竞争弱化 | 价盘、份额或渠道利润持续恶化 | 下调正常化盈利和退出，允许长期负增长 |
| 资本配置失控 | 长期项目消耗核心现金且回报不明 | 提高研究门槛，限制增长与派息假设 |

口径：这些是可复用的情景组织方式；不在本报告写死公司目标价、统一折现率或自动买入评级。

低PE可能反映市场低估，也可能反映盈利不可持续。真正安全边际应能承受终端需求偏弱、费用投入恢复、原料和质量成本变化以及部分资本误配；若只有保持峰值利润与高倍数才能达标，名义便宜并不稳健。商业、日化与药品不同利润来源，应适用与经济特征匹配的研究条件。

买入的研究条件应是生意可理解、主要风险可约束、正常化现金与资本责任相容，而且价格允许保守情景也具有合理回报。仍未取得新行情、逐品终端和完整资本计划时，不在行业报告给当前价格推荐指数。本轮保留原个股模型，行业观点不能自动替代逐股估值复核。

## 十二、后续验证：什么证据会改变判断

围绕产品、渠道、现金与资本建立持续检查清单

| 问题 | 支持优势的证据 | 应降低信心的证据 |
| --- | --- | --- |
| 成熟产品是否保持吸引力 | 同品动销、促销后净价与复购稳定 | 扩渠道但旧区域销售持续下滑 |
| 渠道是否健康 | 终端和经销合理利润、库存与回款同步 | 压货、返利升级、退换货和账期延长 |
| 品牌是否转化为现金 | 完整费用和资产投入后现金持续 | 依赖理财、处置或延长付款支撑分配 |
| 质量责任是否充分履行 | 可追溯供应、稳定质量与正常合规投入 | 质量事件、召回、处罚或投入不足 |
| 新项目是否值得继续投入 | 里程碑、客户价值和资本回收可验证 | 投入扩大但结果、预算和止损不清楚 |
| 高分红能否持续 | 母公司现金、法律利润与长期投入相容 | 持续依赖储备、借款或资产出售 |

口径：新证据应触发逐股重新研究；不等候固定时间，也不因报告导入而自动改变原有参数。

下一轮应优先补各公司同品零售、渠道库存、价格与分部现金，其次是研发和资本承诺。没有这些数据时，保持条件性的成熟经营判断，比用行业平均增长率填满十年模型更诚实。若终端证据恶化，应先调整正常化利润与业务生存条件，再讨论倍数；若只是价格下跌，不自动判定安全边际变好。

最终结论：这个行业的研究价值在于部分产品可能拥有重复需求、品牌信任与资本效率，不在于所有中药公司天然是消费龙头。云南白药重点穿透多业务与资本配置，华润江中重点验证大单品和渠道。先理解持续现金来自哪里，再决定愿意付什么价格，才能把好产品与好投资区分开。
