# 医疗器械行业研究

迈瑞医疗 · 鱼跃医疗

研究日期与口径：2026年10月1日；财务截至2026年6月30日

作者：刘益的复利研究室 · 独立研究

## 需求长期存在，采购、价格与技术却不断变化

医疗器械不是一条统一的增长赛道。医院设备依赖预算与采购，诊断仪器与试剂需要验证装机后的有效使用，家用器械依赖患者体验和渠道，耗材与CGM又有不同的价格和复购约束。2026H1迈瑞收入增长、归母下降，鱼跃收入和扣非均下降，不能仅凭新品或行业叙事认定全面复苏。长期值得研究的，是能用可靠临床价值、质量体系、研发和服务持续赢得客户，并把完整资本责任后的现金留给普通股的企业。国产替代、全球化和AI都要经过净价、利用、费用、回款与新增资本回报验证。

## 一、产业地图：先拆客户与产品，再谈行业增长

设备、诊断、耗材和家用产品，回报机制不同

| 业务 | 收入形成方式 | 关键约束 |
| --- | --- | --- |
| 医院医疗设备 | 设备采购、配置、安装、验收与售后 | 预算、招标、实际利用、替换周期与回款 |
| 体外诊断 | 仪器及试剂，按具体系统形成业务 | 装机利用、检测量、试剂净价与质量 |
| 介入与手术耗材 | 临床使用与配套系统 | 临床价值、术量、准入、价格与竞争 |
| 家用健康检测 | 患者购买、渠道服务与部分配套耗材 | 体验、价格、品牌、渠道和复购 |
| 呼吸治疗及康复 | 不同疾病与场景的设备和服务 | 适用人群、专业支持与短期高基数 |
| CGM等持续监测 | 传感器、系统与持续使用 | 准确性、体验、留存、净价与支付能力 |

口径：分类是商业研究框架；各产品注册类别、医疗适用与收费以实际规定和说明书为准。

“医疗器械”同时包括长期使用的设备和反复消耗的产品，也横跨医院、专业机构、患者与消费者。医院替换一台设备和用户每月购买耗材，对渠道、服务、资本及价格的要求完全不同。公司收入扩大可能来自业务组合改变，而不是所有产品都在同一周期回升。

迈瑞与鱼跃可作为两类经营机制的研究入口，却不能代替全部上市器械企业。迈瑞同时涉及设备、体外诊断和新兴业务；鱼跃经营呼吸、血糖、家用检测、康复与急救等产品。[S1][S2] 对每家企业，应进一步拆客户、产品、地区与权益归属，再从新增收入走到每股现金。

本报告不使用未经核验的行业整体增速、国产化率或未来市场规模预测。没有覆盖完整招投标与终端销售样本，因而不把两家企业的中报表现描述为行业已经确认拐点。目的在于找到未来报告中最值得反复验证的经营事实。

## 二、需求：患者需要医疗，不等于医院立刻购买设备

需求、预算、采购、交付与回款是不同阶段

医疗需求可以长期增长，但设备采购受预算安排、现有资产、科室工作量、人员能力和招采执行影响。一家医院确实需要新设备，并不表示当期已有资金、完成程序或能够形成持续利用。把政策方向、项目批复或招标数量全部当作公司未来收入，容易把时间、客户和中标率的缺口隐藏起来。

| 经营阶段 | 真实含义 | 下一步需要验证 |
| --- | --- | --- |
| 预算或项目安排 | 存在计划，不一定已形成公司订单 | 资金与招采安排是否落实 |
| 招标与中标 | 客户选择或采购程序推进 | 合同、净价、执行和取消风险 |
| 交付与验收 | 产品进入客户工作流 | 实际确认收入规则与回款 |
| 装机后使用 | 设备被投入工作 | 利用、检测或手术量、服务成本 |
| 替换与续购 | 客户愿意继续使用产品体系 | 价格、竞争和跨代兼容 |
| 收款与经营现金 | 账款转为现金 | 是否靠缩减库存或延长付款维持 |

口径：具体合同与收入确认须核各公司会计政策；本表不声称已有完整订单和客户利用数据库。

设备更新可能替代原有采购，而非在原规模之外全部新增；新装机也需要人员和服务能力，不能把市场可配数量直接等同可售数量。若旧设备仍可满足临床需求，价格和售后条件就可能比新功能更重要。研究增长，应把需求、预算、替换、份额和净价分别建成条件，而不是一个共同增长率。

家用器械又有另一层限制：疾病人数与能够持续购买、正确使用产品的人数并不相同。产品易用性、医疗支持、收入与支付、替代方案都会影响真实消费。慢病或老龄化值得长期关注，但不足以直接把全部患病人群乘上某设备价格，得出上市公司利润。

## 三、护城河：临床可靠性和服务体系，比产品数量更重要

技术、流程、渠道和质量需要形成共同优势

医疗器械客户购买的不是单一参数，而是可靠结果、效率、操作体验、维护与可持续供应。医院的使用培训、工作流、数据连接和售后，会影响切换成本；患者则需要在日常环境下正确使用。优质企业应在合理总成本下持续满足这些需求，而非仅以产品系列更多或注册证更多证明竞争力。

| 竞争能力 | 应看到的经营结果 | 潜在失效机制 |
| --- | --- | --- |
| 可靠性能与质量 | 在实际使用中稳定、可追溯，服务响应及时 | 质量问题、误差、召回或专业口碑下降 |
| 产品与工作流适配 | 有效使用、客户续购和合理切换成本 | 系统封闭但体验差，客户寻求替代 |
| 研发与制造 | 新产品有需求且规模化质量稳定 | 研发多但商业转化弱，制造成本恶化 |
| 专业渠道与服务 | 客户覆盖与回款支持完整费用 | 依靠高返利、长账期或不合规推广 |
| 规模与协同 | 共用能力降低总成本、提高资本回报 | 品类增加导致管理复杂度和投入失控 |

口径：这是可复用研究清单，不代替产品性能试验或临床安全比较。

高研发费用率不是单独的好坏信号。成熟平台投入较少却能可靠迭代，可能有效率；在关键技术、质量和服务上持续欠投入，则可能短期利润较好、长期优势变差。判断研发，需要看项目选择、临床价值、成功转化、制造可行性和后续维护。尚未披露的研发成功率不能自填为事实。

AI和软件可能改善设备使用与工作流，也可能需要长期维护、数据治理和合规。装机、合作医院、试点或演示，不自动等于独立软件收入和高毛利订阅。若只有战略描述而没有价格、付款、续费与完整成本，应先把其视为可能的产品竞争能力，不另造一块确定的估值溢价。

## 四、体外诊断与耗材：装机之后，仍要验证真实使用

持续收入由有效检测和合理净价决定

设备与配套试剂可以形成持续关系，但经济价值不由累计装机台数直接决定。闲置设备、低检测量、低价试剂、渠道备货或额外服务负担，会使装机增长与利润脱节。研究必须观察可比的活跃客户、单台实际检测与试剂使用、净价、损耗及客户留存，而不是把设备装机当成永久耗材年金。

| 观察项目 | 对应的经济问题 | 需避免的重复或误判 |
| --- | --- | --- |
| 设备销售或投放 | 谁支付设备与服务成本 | 设备投入和试剂毛利只计好处 |
| 检测与消耗 | 真实使用带来多少重复收入 | 渠道采购等同患者检测 |
| 试剂净价 | 折扣、采购与组合如何变化 | 目录价替代实际收入价 |
| 产品兼容与质量 | 客户继续使用的理由 | 封闭系统代表永远不会切换 |
| 售后与供应 | 可靠使用需多少持续投入 | 高毛利未扣专业服务费用 |
| 营运资金 | 试剂、库存、账期和回款 | 扩大装机不需要新增资金 |

口径：各诊断系统和合同机制不同，不能套同一单台试剂收入。

手术和介入耗材也需要把临床使用量与实际净价相乘，再扣制造、研发、专业推广与服务。技术升级可以改善价值，但原有产品可能被替代，不能将旧产品全部保持再额外增加新品收入。集中采购的价格变化、产品范围和执行区域应逐项核，量增不一定覆盖价格下降。

新兴业务较高增速可能来自低基数、并购、产品替换或市场突破，其完整权益利润未必与收入同比一致。如果新业务属于控股子公司，集团合并收入不能全算上市公司普通股收益。研究应区分收入、经营利润、少数权益、并购价格与实际汇付。

## 五、家用与CGM：持续使用是优势，也是必须验证的条件

从硬件购买走向用户留存，而不是只算市场渗透率

家用检测设备常需要稳定品牌、准确测量、容易操作和便利渠道。单次硬件购买不等于每年复购；配套试纸与传感器则需要看实际使用。CGM具有持续监测和耗材属性，但能否形成长期现金，取决于使用体验、适用范围、准确性、留存、净价与完整费用。用户注册数和应用下载量不是付费活跃用户。

| 业务 | 主要现金机制 | 应单独验证 |
| --- | --- | --- |
| 血压等家用检测 | 设备销售与替换 | 质量、体验、价格和真正终端需求 |
| 传统血糖检测 | 设备加按需试纸使用 | 有效用户与试纸消耗、净价 |
| CGM | 持续传感器购买与系统使用 | 新增转留存、使用天数、价格及利润 |
| 家用呼吸治疗 | 设备、配套及服务 | 专业支持、持续使用与售后责任 |
| 制氧和季节性产品 | 购置需求与替换 | 异常高基数后正常需求 |
| 急救与康复 | 具体场景采购与服务 | 安装不等于持续使用，维保责任需计入 |

口径：不提供适用性或个人医疗建议；不同产品之间的临床差异不能由收入增速证明。

鱼跃中报称CGM业务收入增长超过一倍，但未在本报告取得独立的CGM绝对收入、利润和用户留存。[S2] 因而可以把它列为重要补证点，不能将整个血糖管理及POCT收入都当CGM，也不能把这一增长率直接当集团未来利润率。新技术的用户体验和竞争价格，应与商业扩大同步核验。

持续耗材有机会提高收入重复性，也可能受到价格下降、竞品体验、用户支付与渠道费用制约。若获客成本上升，用户使用不持久，持续收入的高估值就可能被过早支付。更稳健的验证是分新老用户、看真实留存和完整贡献利润；缺少公开样本时保留空缺，不自造平均用户终身价值。

## 六、监管与价格：准入是基础，商业兑现还有下一步

注册、质量、招采、支付和数据责任不能互相替代

医疗器械监督管理条例以风险分类、注册或备案及全生命周期质量责任为制度基础。[S3] 对投资研究而言，获证代表完成相应准入步骤，不表示已经进入所有医院、获得支付或形成客户购买。临床、质量、追溯、服务与合规成本，需要在全生命周期持续保留，不能仅作为一次性投入。

| 制度或经营环节 | 需要核验 | 不能直接推出 |
| --- | --- | --- |
| 产品注册或备案 | 具体产品、范围、地区和有效期 | 获证即大量收入 |
| 生产与质量责任 | 实际体系、持续监测与召回安排 | 质量费用可以在利润修复时削减 |
| 招标及采购 | 净价、范围、执行和付款条件 | 中标金额等同已收现金 |
| 医疗支付与临床使用 | 项目、地区、预算和利用 | 病人需求必然变成厂家销售 |
| 海外准入 | 当地具体许可与适用范围 | 一地区获证可在全球销售 |
| 数据与软件 | 合法使用、产品责任及持续运维 | AI试点已形成高利润订阅 |

口径：条例引用为制度基础，不是对截至研究日全部产品和地区最新法律的全面核查；具体执行须重新核原文。

集采和价格竞争可能扩大规范企业份额，但也会压缩单位利润；不能统一假设行业经历一次降价后风险已经消失。价格、量、产品替换、服务和渠道费用是联动变量。应逐品类、逐区域检查影响，而不是使用一个行业平均降价系数调整全部公司盈利。

医疗合规风险还可能影响销售方式与客户决策时间。稳健企业需要把合规作为经营条件，而非估值模型里可忽略的偶发罚款。若增长依赖不可持续推广或不透明交易，历史高利润不能作为正常化起点。对尚未核实的监管事件，不作推断，只记录具体待核问题。

## 七、全球化：注册、服务和现金回收共同决定价值

海外收入增长与海外普通股利润不是同一个指标

走向海外不只是出口一台设备。当地许可、售后、培训、备件、临床支持、供应链与客户信用都会影响完整回报。不同地区的支付、汇率、渠道和竞争结构不一样；“海外”不能当一个统一高毛利市场，也不能从收入占比上升直接推导净利率提高。

| 进入方式 | 可能的优势 | 新增资本和风险 |
| --- | --- | --- |
| 经销出口 | 利用渠道、初期投入较少 | 控制力、库存、信用与终端信息不足 |
| 属地销售与服务 | 贴近专业用户，提高响应 | 人员、备件、合规与持续运营投入 |
| 本地供应链与生产 | 交付、注册和采购适配 | 建设、利用率、质量与管理复杂度 |
| 跨境并购 | 补齐技术、产品或地区能力 | 价格、商誉、整合、少数权益与资金汇付 |
| 高端市场突破 | 提升产品认可与单位价值 | 需要证据、服务和更长客户验证 |

口径：这是经济机制分析，不假定任何公司在所有地区已完成上述能力。

汇率会影响折算与经济收益，但不能只加回亏损、保留收益来得到“真实盈利”。出口售价、采购、海外费用、现金归属与套保需要配对。当地形成利润后是否可以、何时可以向上市主体汇付，也是普通股现金的重要边界。

国际化质量的研究顺序，应是产品与客户认可、合理净价和服务成本、回款、再到新增资本回报。收入快速增长可以是早期信号，却不是完成验证。鱼跃外销和内销的经营机制与毛利不同；迈瑞多业务的国际布局也不能给每个新项目套同一成功概率。

迈瑞收入增长而归母与扣非下降，说明收入恢复尚不能直接代表权益盈利恢复；鱼跃归母下降幅度高于扣非，提示要分开主业和非经常性影响。这些是公司事实，不是全行业分布。本轮不使用自动参考稿所称的总体利润拐点，因为其样本、权重和可比口径没有独立核清。

两家公司经营现金均为正，但其变化还受到采购、应收、库存和付款时间影响。现金减购建只是一个有限观察窗口；迈瑞合并经营现金为48.77亿元，不采用检索曾返回的母公司32.65亿元替代。合并和母公司都有分析意义，却不能混用或相加。

本表只建立行业讨论的事实基础，没有刷新个股模型、价格与排名。最新报告日期也不代表全站股票已经重新研究。后续如更新当前买入条件，应另行核股价、普通股口径、已除息分红、资本责任与正常化利润，不能把中报盈利简单翻倍。

## 九、资本与现金：研发、设备、并购和周转都要承担

低当期购建，不等于长期无需投入

器械企业研发与服务责任持续存在。费用性研发通常已经进入利润与经营现金，不能在现金桥接中再全额重复扣除；资本化研发和建设则需核投资支付。设备投放、备件、存货、应收与售后也可能随客户扩大占用资金，因此高毛利并不等于低资本需求。

| 现金层次 | 需要穿透 | 常见误判 |
| --- | --- | --- |
| 盈利到经营现金 | 非经常性、应收、库存、预收与付款 | 所有扣非利润都已收现 |
| 资产投入 | 维护、扩张、资本化研发、设备投放 | 当期低购建可永远保持 |
| 并购和金融安排 | 收购支付、股权归属、定存和受限资金 | 现金充足即可不计并购代价 |
| 集团到普通股 | 少数权益、母公司汇付与法律分配 | 集团现金全部由上市普通股支配 |
| 分红和回购 | 已实施权利、资金用途与未来股本 | 回购既增EPS又额外加现金收益 |
| 持续竞争力 | 研发、质量、服务与风险缓冲 | 高派息可以不影响下一轮竞争 |

口径：对真实公司需形成逐年资本与分配桥接，行业表格不代替这一核验。

短期回款改善可能来自一次性减少库存、收回旧账或延后供应商付款。这些调整有意义，但不能持续十年重复释放现金。正常化现金需要穿越经营周期，并与增长、分红、维护和偿债共同成立。若模型同时设高增长、低留存和低维护，必须说明谁承担新增投入。

并购的协同应从实际权益与收购价格计算。子公司收入全部并表，不等于全部利润属于上市公司普通股；新增业务高增长，也不说明并购资本回报超过机会成本。收购、商誉、未来投入和少数权益需要一起解释，不能仅保留新增收入而删去付出的现金。

## 十、公司差异：迈瑞看系统与专业客户，鱼跃看产品与用户

同属器械，但研究问题不能共用一套答案

| 公司与产品 | 2026H1披露 | 经济含义与边界 |
| --- | --- | --- |
| 迈瑞·医学影像 | 收入28.36亿元；同比 −5.78% | 集团增长不能证明所有产线恢复 |
| 迈瑞·新兴业务 | 收入31.10亿元；同比 +19.59% | 收入增长需继续桥接投入、少数权益与利润 |
| 鱼跃·呼吸治疗 | 收入14.51亿元；同比 −13.33% | 成熟品类压力不能被新品叙事覆盖 |
| 鱼跃·血糖及POCT | 收入7.95亿元；同比 +17.94% | 不等同CGM收入，更不等同CGM利润 |

口径：来源[S1]第27—28页、[S2]第15—16页；人民币亿元，网页四舍五入。各公司产品分类不同，不将这些行当作可直接互比的同类市场份额。

迈瑞的研究重点是跨产品专业客户体系能否持续改善价值与资本效率。设备、诊断、新兴产品和数智方案可能共享能力，也带来不同周期与质量责任。高端替代与新业务机会需要以客户利用、净价、服务、研发和权益现金验证。组合更丰富不是自动分散风险，若多条业务同时加大投入，资本与组织需求反而会提高。

鱼跃更应按呼吸、家用检测、血糖及其他品类分别判断。成熟设备的收入和替换周期，与CGM传感器的持续用户逻辑不同。公司可以用品牌和渠道帮助新品起步，但品牌迁移、长期留存和贡献利润仍须证明；如果成熟产品下降、新品尚小，不能用新品高增速直接覆盖集团盈利变化。

| 公司 | 研究优先级 | 最重要的反证 |
| --- | --- | --- |
| 迈瑞医疗 | 设备与诊断使用、产品净价、研发服务效率、并购权益与海外回收 | 收入增但权益利润与完整现金持续弱化 |
| 鱼跃医疗 | 成熟产品需求、CGM真实规模与留存、外销完整利润和渠道周转 | 高增长新品无法覆盖旧业务压力或获客投入 |
| 两者共同 | 临床可靠、质量、客户体验及资本纪律 | 质量或合规问题，资本回报长期低于新增投入 |

口径：这些为独立投资研究的问题排序，不表示大师本人意见或当前持仓。

企业都有创新和国际化方向，也应保留不同风险画像。迈瑞面临专业采购、技术迭代及多业务整合；鱼跃面对消费者与渠道、品类周期和新品商业化。使用统一增长、统一折现门槛和同一退出PE，会把这些差别抹掉。行业报告应帮助逐股参数更有依据，而非提供又一个统一模板。

## 十一、估值：为可验证的利润付钱，不为全部潜在空间付钱

增长、分配与退出必须和资本责任相容

估值起点应是正常化归母利润与现金，而非疫情高峰、单季度修复或新业务最高增速。研发、必要服务和合规属于持续经营成本；非经常性收入、资产处置和金融收益则需核税后与权益。公司调整利润有参考价值，但不能直接当统一口径EPS，更不能把全部研发加回后仍假设永久技术领先。

| 情景 | 经营条件 | 需要共同调整的估值变量 |
| --- | --- | --- |
| 成熟稳定 | 用户价值、净价和完整投入可保持 | 低增长、合理留存、成熟退出 |
| 采购修复 | 预算到交付、利用和回款逐步落实 | 恢复时间、费用和资本需求 |
| 创新成功 | 真正持续使用与正贡献现金 | 成功速度、获客、研发和留存 |
| 价格压力 | 量增不足弥补净价或费用变化 | 正常化利润、长期增长与退出 |
| 技术或质量受损 | 客户流失、替代或合规责任扩大 | 先看生存与资金，不靠低倍数掩盖 |

口径：这是情景构造框架，没有写死当前目标价、具体分数或共同回报要求。

高质量企业也可能在高价格下回报不够；低估值企业也可能因为利润下降而不便宜。安全边际应承受采购延迟、价格竞争、新品转化偏慢、海外服务费用与质量责任，而不只是将乐观预测打一个比例折扣。倍数退出也应反映十年后技术、客户与资本回报的实际成熟状态。

若核心利润与现金仍可理解、风险可约束、价格允许保守条件形成合理回报，可以进入逐股深入研究；若主要价值依赖未公开的用户留存、尚未形成利润的软件或全部成功的新项目，应先补证。没有新行情和充分资本桥接时，不提供行业统一现价评级，也不通过行业报告改变本站排名。

## 十二、后续验证：把技术进展转化为可检查的经营证据

从需求到普通股现金，沿真实链条更新判断

| 研究问题 | 提高信心的证据 | 降低信心的证据 |
| --- | --- | --- |
| 采购需求是否兑现 | 执行订单、交付验收、利用与回款同步 | 只见计划和中标，执行延期或现金弱 |
| 诊断装机是否有效 | 检测与试剂复购、净价和服务回报稳定 | 装机增长但试剂与利润不匹配 |
| 家用新品是否留住用户 | 实际使用、复购与完整贡献利润改善 | 新增用户多但留存低，获客费用上升 |
| 海外是否创造权益现金 | 当地费用、信用、资本和汇付后回报合理 | 销售增长但应收、投入与亏损同步扩大 |
| 研发与质量是否可持续 | 可靠产品转化、合规与服务投入充分 | 商业结果落后，质量或召回责任增大 |
| 分配路径是否可信 | 母公司现金、法律利润与资本义务相容 | 依靠储备、处置或融资长期支撑分配 |

口径：指标需按公司、产品和地区核查；相互矛盾时保留差异，不用一个综合评分掩盖。

下一轮补证应优先选择能够改变估值的项目：迈瑞的设备与试剂利用、采购回款和权益现金；鱼跃的成熟品类需求、CGM收入利润与用户留存、外销完整成本。若只能取得公司战略描述，应保留条件判断，不将缺失填为零，更不以自动报告的行业拐点替代公司数据。

最终结论：医疗器械存在长期需求与技术进步机会，但其经济回报受价格、采购、实际使用、研发和资本责任共同约束。专业平台和消费者品牌各有优势，也各有失效方式。长期研究应寻找持续客户价值与每股现金，而不是在“国产替代、慢病、AI、全球化”四个标签上叠加永续增长。
