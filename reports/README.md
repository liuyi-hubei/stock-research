# 研究报告归档

研究报告按内容类型分为两个分类：

- [`stocks/`](stocks/)：个股研究报告，现有个股内容均归档于此。
- [`industries/`](industries/)：行业研究报告，已收录白酒板块景气度分析报告。

网页端通过顶部“个股研究 / 行业研究”进入相应列表。归档文件不会自动成为网页，须登记结构化数据或生成阅读页。

华能蒙电全面体检报告归档于 `stocks/华能蒙电600863_全面体检报告.md`，阅读页为 `report-600863-20260921.html`，从华能蒙电个股页进入。它保留独立报告日期与数据口径，不覆盖原有估值模型。修改原文后运行 `node docs/render-archive.mjs` 重新生成页面。
