# 个股报告

本目录用于集中保存个股研究报告，统一使用 Markdown（`.md`）格式。

## 文件命名

建议使用：`股票名称-股票代码.md`

例如：

- `泸州老窖-000568.md`
- `贵州茅台-600519.md`
- `腾讯控股-00700.md`
- `美的集团-000333.md`
- `紫金矿业-601899.md`
- `泡泡玛特-09992.md`
- `五粮液-000858.md`

同一只股票的后续研究可以直接更新原文件；如需保留历史版本，可在文件名后增加日期，例如 `泸州老窖-000568-2026-09-13.md`。

## 报告内容

报告应尽量包含：研究日期、数据口径、核心判断、各投资框架分析、估值与结论、风险因素、买入前提及后续验证事项。

本目录是个股内容归档区，网页展示所需的数据结构仍维护在 `data/` 目录中。
