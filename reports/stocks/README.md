# 个股报告

本目录用于集中保存个股研究报告，统一使用 Markdown（`.md`）格式。

## 文件命名

建议使用：`股票名称-股票代码.md`

例如：

- `泸州老窖-000568.md`
- `贵州茅台-600519.md`
- `腾讯控股-00700.md`
- `美的集团-000333.md`
- `紫金矿业-601899.md`
- `泡泡玛特-09992.md`
- `五粮液-000858.md`
- `长江电力-600900.md`
- `华能蒙电-600863.md`
- `招商银行-600036.md`
- `中国平安-601318.md`
- `华润江中-600750.md`
- `格力电器-000651.md`
- `福耀玻璃-600660.md`
- `青岛港-601298.md`
- `三七互娱-002555.md`（行情2026-09-23，财务2026H1，另附数据核验说明）
- `华能国际电力股份-00902.md`（港股；行情2026-09-23，财务2026H1，另附币种与普通股利润核验）
- `安踏体育-02020.md`（港股；行情2026-09-23，财务2026H1，另附正常化利润、PUMA交易与可转债核验）
- `新城发展-01030.md`（港股；行情2026-09-23，财务2026H1，另附吾悦商业、债务、REITs与模型核验）

同一只股票的后续研究可以直接更新原文件；如需保留历史版本，可在文件名后增加日期，例如 `泸州老窖-000568-2026-09-13.md`。

## 报告内容

报告应尽量包含：研究日期、数据口径、核心判断、各投资框架分析、估值与结论、风险因素、买入前提及后续验证事项。

本目录是个股内容归档区，网页展示所需的数据结构仍维护在 `data/` 目录中。
