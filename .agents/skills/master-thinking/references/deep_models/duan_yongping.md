# 段永平投资框架：分析与决策模型

按用户2026-10-24提供的《段永平投资框架总结》重新组织，替换旧版。依据DOC-060《投资问答录》、DOC-187已整理原帖及[补充来源说明](../duan-framework-source.md)。编译问答须保留日期和情境；第三方总结、本人表达与研究者实现分别归因。

## 一、体系总纲

**定义**：买股票是买公司，买公司是买其整个生命周期的未来净现金流。不是买短期报价、市场认同或长期持有标签。十年模型不是企业寿命。

**做对的事情，把事情做对**：前者判断方向与是非，错了及时改，不等回本；后者容忍并修正正确方向中的过程错误。不能将暂时经营困难直接判为方向错误，也不能用过程犯错替诚信或模式缺陷开脱。

**先检查不为清单**：价值观是约束，不是估值后的装饰。能力圈、商业模式与企业文化、估值按此顺序研究，不做加权评分。理解或企业质量不成立时停止积极买入论证，允许继续研究，不能靠便宜补救。

框架解释保留能力圈等原始概念；完整公司报告采用[个股研究规范](../个股研究规范.md)六章，不把用户能力圈作为评判对象，不在正文写个人纪律，也不使用闯关式标题。

## 二、不为清单

- 不做空，不用保证金或借款买股，不用近期必要资金追求非必要收益。
- 不碰不能理解的投资，不抄任何人作业；公开持仓只能提供研究线索。
- 不以看图看线、预测大盘、抄底追涨代替生意和价值判断。本约束属于段永平，不改写鹿鼎公独立模型。
- 不以年度回报目标、必须赚多少或必须翻本驱动动作。机会成本比较、条件回报计算不等于设定必须实现的收益目标。
- 黄金、比特币等不产生企业经营现金的资产不套本模型给出经营价值买点；不把不同性质的资产一概判为负价值。
- 发现原理解错误及时纠正；错过不是必须追回的损失。

个人资金、杠杆与期限未知时说明未核实，不替用户认定约束已通过，不执行真实交易。

## 三、能力圈

### 判断企业未来，不是检查资料是否齐全

先形成可解释、可证伪的认识：公司靠什么持续赚钱，谁为其产品付钱，竞争为何难以夺走需求，维持生意需要多少资本，现金最终归谁。再用数据验证。不能先堆财务资料，再用缺少资料替代能力圈判断。

理解不要求准确预测每季或每年利润，也不要求未来没有不确定性；必须大致把握长期现金产生能力，分清可容忍的估计范围和会改变生意本质的未知。流程简单、产品熟悉、持有多年或他人重仓均不能证明理解。区分“本轮未研究完”和“研究后仍看不透”。

### 所有权与下跌检验

1. 假设买下整家公司、十年没有上市交易，是否仍愿意拥有？回报靠经营现金、留存再投资，还是只能靠更高价接盘？
2. 企业持续经营的核心条件与主要反证是什么？不能只写未来不确定。
3. 股价大跌但事实未变时，重新判断是否仍愿意按当前价格拥有。想加仓是自查线索，不是“真懂”的充分证明；事实恶化后卖出不能机械判为不懂。
4. 独立给出理解边界，不向他人借确信。无法理解时等待、放弃或错过均是合格输出。

安全边际首先强调对企业未来的理解，不只看价格折扣；这不取消价格约束。DOC-060在2015-01-21、2015-01-22已有理解度表达，不沿用“2020年才转变”的切分。

## 四、商业模式、企业文化

两者分别评价，都是买入必要前提。文化不是泛泛管理评分；优秀管理也不能挽救结构上没有经济性的模式。

### 商业模式：三个核心问题必须逐项分析

**1. 护城河是否长期坚固**

从用户需要、竞争者难以满足的差异化出发，不以外观不同、品牌历史或行业第一代替。回答：用户得到什么价值，为什么持续付费，竞争者即使投入时间资金为何仍难抢走生意，差异化能保持多久，什么变化会破坏它？

品牌、技术、习惯、网络与切换成本必须落实为具体用户价值和竞争机制。有护城河是重要条件，不等于仅凭护城河就证明模式优秀。不能把茅台、苹果的成功移植给其他白酒或制造商。

**2. 长期毛利率是否合理**

观察多年及跨周期毛利，解释其反映的产品可替代性与定价能力，区分持续差异化、阶段供需、成本变化和会计口径。不能只引单个半年度高毛利，然后用一句“仍待观察”结束。

低毛利、长期降价与费用换量是优先排查的弱差异化信号，但必须解释本公司业务与资本需求，不设跨行业统一毛利门槛。高毛利也不能掩盖销售费用、资金占用或需求不可持续。

**3. 长期净现金流是否令人满意**

核心是理解未来持续创造现金的能力，不是计算过去现金均值或只问本期派息。未来利润、增速和寿命不是当前已知事实；从需求、竞争、定价、费用、必要投入与资本回报判断现金可能保持、改善或下降。历史利润与现金只作参考校验，不能机械外推。

观察现金长期是否匹配利润，增长是否必须不断追加低回报资本，竞争是否持续消耗所得。最终比较所有者经济性，不是同行排名；净利润是线索，单期经营现金减购建也不是已验证的普通股净现金。

只有形成有依据的粗略现金量级时才估值；否则承认暂不能合理量化，不任意指定现金转化率、贡献年限或衰退曲线。现金流折现是价值原则，不是强填逐年数字的任务；可复算不等于假设可靠。

必须形成完整链条：**用户需要的差异化 → 长期竞争保护 → 合理而持续的毛利 → 令人满意的长期净现金流**。每项给公司事实、因果解释、反证与判断；渠道、动销、库存、返利和短期业绩只是验证证据，不能取代商业模式分析。

### 商业模式直接排除条件与待核信号

优先排查无持续差异化而靠价格战、缺真实产品价值而靠营销、以性价比口号掩盖低价竞争，以及必须依赖补贴、融资或压货的增长。实质证据证明生意必须长期如此才能成立时，停止该视角买入论证，不以估值便宜解救。

文化上，反复撒谎、隐瞒、侵占利益，或持续为短期利益伤害消费者与长期股东，若有实质证据并构成持续/不可修复问题，也直接停止积极买入论证。区分“未发现实质否决证据”“存在待核信号”“已触发否决”；缺证据不等于通过，也不反推有罪。完整清单按写作规范执行。

营销活动不等于营销驱动，低售价不等于坏模式。航空、硅片、同质化电动车等是反查差异化与竞争的案例，不凭行业名替公司下结论，也不为熟悉的消费品牌降低标准。

### 企业文化：从反复言行判断是非取舍

- 听其言观其行：历史承诺兑现与否，未兑现是否诚实解释？
- 短期利润与消费者、员工、渠道和长期股东利益冲突时，以是非还是眼前利益为准？
- 是否反复撒谎、隐瞒或侵占利益？实质负面信号权重大，不能被好业绩与便宜抵消。
- 将企业拟人化，是否愿意与这样的人长期打交道？以具体行为支持，不能只凭个人好恶。
- 最高领导是否践行公开价值观，是否有利润之上的追求，是否把消费者需要放在短期利益之前？

列有日期的正面、负面和未核事项。看出坏文化通常比证明好文化容易；未发现负面不是已通过。一次控量或分红表态不能完成文化评价，本轮未查完也不等于企业不可信。

## 五、估值：先有认识，再毛估估

### 四步粗估

1. **经营买入代价**：辨明股份、币种、整体市值，检查现金、短期可变现资产与负债。用户总结的“市值减净现金”是起点；研究者财务实现必须区分多余/经营必要现金、受限资金、有息/经营负债、租赁和其他实质义务。不能机械套现金加短期资产减总负债；额外调整标明研究者实现。
2. **当前盈利基础**：看当年利润，以历史核对是否反映正常经营；周期高低点、一次性项目和权益归属分开，不把半年翻倍当正常年度利润。
3. **未来5—10年及更长期盈利走向**：基于生意理解粗估方向与量级，解释为何保持、增长或下降，不填满没有依据的精确逐年增长率。
4. **股东回报途径**：分红、价格合理的回购、留存再投资如何增加每股未来所得；核权益、资金和时序，不重复计收益。

### 机会成本与价格

与同币种、相近期限的长期国债/存款及真正可选机会比较，注明日期、口径和风险差异。约12倍PE、10%增长、30倍PE仅为情境例子，不设永久买卖线。对十年后生意的认识是判断今天价格的基础；历史高点、成本与跌幅不是价值锚。

不择时不等于追高：关注价格相对长期价值，价格不合适可以持现金，不为抓最低点预测大盘。

现金流折现是总纲，毛估估不是不做功课，也不是禁止算术或透明区间计算。DOC-060的2010-04-27问答将DCF与毛估估联系起来；反对的是用不可靠变量制造精确感。网站共同IRR可作研究者辅助，不伪称段永平本人模型，不以计算过线替代生意理解，不擅自改算式或参数。

### 财报的角色

优先用财报排除负债与融资风险、现金和利润长期失配、不合理开销及资本占用，不能仅凭漂亮报表选公司。利润与现金长期脱节、现金持续恶化，须解释原因并判断是否否决，不能随意调整加回。

单年营运资金波动不等于造假。不能仅因净资产高就认定有价值；也不把所有非直接生息的厂房或土地统一算负价值。“财报用于排除”不意味着禁止核验或使用财务事实，财报应服务生意判断而非成为选股答案。

## 六、买入、持有、卖出与集中

- 买入先确认理解且愿意拥有的好生意，再评价格；不靠名人、跌幅或历史高点。
- 持有按当前机会独立重评，与成本无关；不套牢变长持，不因已赚钱本身卖出。
- 模式/文化出现不可修复问题，或发现原理解错误，及时重审纠正，不等回本；暂时执行困难与结构/是非错误分开。
- 一点点高估不机械卖出，考虑经济性、机会成本和税费；也不将模式或文化损伤写成唯一可能卖因。
- 理解程度影响集中度，但须结合资金、期限、相关敞口与被迫卖出风险。“至少1/6”不是硬仓位：DOC-060的2024-04-21原问答明确保留价格与机会条件。
- 不理解时允许不参与；指数基金可作为另一种路径讨论，不自动推荐具体产品。不把卖put、期权或小仓参与当绕过能力圈的许可。

## 八、输出与检查

不为清单与做事原则作为内部研究纪律执行，不在个股正文输出个人认知教育或通用行为清单，除非用户明确询问方法、个人配置或具体风险问题。公司报告按写作规范交代模式三问、文化行为、安全边际与可估值程度、机会成本、当前判断及失效条件；不能量化时不强给买价与IRR。简短问题只答相关部分，不强制固定篇幅或堆免责声明。

先形成对生意的认识，再用财报、公告、研报、行业与行情证据支持或推翻。禁止先铺数据，最后一律用“证据不足”替代研究；确实无法判断时指出是哪项实质未知阻断，不为填表编造通过或硬报价。

本人原则、特定时点表达、第三方总结、研究者实现和公司当期事实分开归因。DOC-187近期实践已入正式资料，日常不要求重爬；被回复者文本不归因段永平。
