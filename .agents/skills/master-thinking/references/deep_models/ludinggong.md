# 鹿鼎公投资法

依次判断资产、盈利、价格，再讨论仓位与交易。使用基于公开材料重建的研究方法，不冒充作者本人，不把整理者的解释当成作者原话。

## 先读资料

- 首次使用、讲解方法归属：读 [证据与来源](../ludinggong/evidence.md) 和 [覆盖范围](../ludinggong/coverage.md)。
- 分析公司：读 [分析与计算](../ludinggong/analysis.md)。
- 仓位、做T、网格：再读 [操作与演变](../ludinggong/operations.md)。
- 复盘作者、周期股、组合：读 [案例与反例](../ludinggong/cases.md)。
- 查找更多历史发言：用 [580条目录链接](../ludinggong/archive-urls.json)。索引不代表580篇已全文读完。

## 证据与时效

区分 A 作者账户原帖正文已读取、B 资料站转载的正文与对话已读取、C 他人解释、D 本 skill 的研究实现。优先 A，再用 B；C 仅作线索。将 B 称为“资料集收录的发言”，不得称全量原帖核验。重要归因附标题、日期与链接。

查证最新行情、财报、公告、分红及行业数据，标明日期、市场、币种和口径。优先公司、交易所、政府及行业原始统计。无法获取时明确缺口，作条件分析。不得将旧案例数据当当前事实。

不得宣称作者固定年化收益、无年度亏损、从不止损或只投某类企业。分开主仓、游戏仓、农历年与自然年；不得拿单月亏损冒充最大回撤。

## 1. 价值选股：可持续盈利优先

先分析行业供需、替代风险和公司地位，再回答：

1. 利润靠资源、成本、一体化、品牌、渠道、技术还是特许经营保护？
2. 行业低谷会损失多少？盈利底线有证据吗？
3. 利润能转成现金吗？债务、维持性资本支出和营运资金吞掉多少现金？分红靠经营还是融资？
4. 价值是否永久受损？区分股价下跌与企业盈利恶化。
5. 是否真正理解行业、企业和估值方法？不懂可以不投。

周期股至少给悲观、正常、乐观盈利及现金流；以正常或低谷利润检验安全边际，禁止用景气顶点的低 PE 证明低估。恢复型机会需要明确恢复条件，不当作已兑现事实。

给“适合研究 / 条件成立后再研究 / 当前不符合”的判断。好资产不自动等于好价格，也不自动等于适合当前投资者。

## 2. 趋势选时：经营、周期与市场分别评估

检查经营兑现、库存与供需变化、融资环境、价格量能、回购和股息吸引力；分别标注事实与推断。

不得把趋势选时简化成追涨或固定均线。作者既讨论过左侧低估买入，也讨论过等待经营改善兑现。按情境判断，保留其方法变化。

给买入条件、暂不买的理由、下跌与反弹时的应对。不要求“完美底部”全部指标同时成立，也不因跌幅大就判定见底。

## 3. 估值定仓：价格与确定性共同约束资金

以可持续现金流、分红、增长、利率及替代机会建立正常价值和保守价值区间。合理价不自动等于买点。

低估加深且盈利可靠，才支持更高配置；估值上升、盈利底线下修、置信度下降或更好替代机会出现，降低配置意愿。比较替代品时同时比较风险、增长和分红，不只比 PE。

请求具体仓位时结合已知资金、现有持仓、未来用款和可承受损失；资料不足则给方向和条件示例，不伪装精确最优比例，不为非必需信息暂停研究。

有仓位 w 时测算单项损失约 w×该股跌幅；进一步考虑同行业、同宏观因子的同时损失。持有很多股票不自动等于分散。保留流动性，不把生活资金和大杠杆当耐心资本。

量化计划属于 D：按公司独立设置最大预算、买卖档位与失效条件。不得默认 PE<12、股息率4%、下跌10%或某均线是作者普适仓位铁律。

## 4. 波动降本：价值判断成立后再用交易

先检查能力、时间、资金及费用后的价差，允许“不做T”。

- 低估区讨论底仓配合小额先买后卖，核查新增资金与最坏仓位。
- 合理区讨论先卖后买，接受卖飞，不追买破坏估值纪律。
- 高估区优先讨论减仓，不默认所有卖出均回补。
- 基本面恶化、估值锚失效时重估或退出，不靠做T挽救永久亏损。

历史价差与数量示例见 operations.md，不直接当今天的订单参数。核实当前交易制度、费用、滑点和回补约束；未获明确指令不执行真实交易。

分开核算交易收益、剩余持仓成本、分红和总资产收益。成本变低可能来自分红或出售，并不证明做T成功。红利复投与交易降本分开；买到更多股份不保证近期净值上涨。

## 输出

先直接回答用户问题。完整分析按四步给出：资产与盈利底线；时机证据；价值区间与仓位方向；是否不动、分批或交易及失败处理。最后列改变结论的关键数据、日期和假设。

保持独立判断，不替用户持仓寻找利好，不捏造评分、概率或数字。仅解释方针时简短作答，不强制完整报告。
