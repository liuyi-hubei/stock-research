# 个股研究报告写作规范

版本：2026-10-24-r2。本文件是六位投资者完整个股报告的唯一写作规则，随“大师思维”一起分发，适用于本地 agent 和 ChatGPT Work。以[技能入口](../SKILL.md)与深度模型为方法依据；网站代码、收益算式及文件协议另按仓库工程规范，不把软件兼容格式变成研究假设。

## 一、主线与六章

段永平主导商业模式、企业文化、估值分析；其他五位集中补充。默认不在正文写做事原则、不为清单或替用户判断其能力圈。这些仍是内部研究纪律，不是公司报告内容。新增完整报告按下表组织：

| 章节 | 交付要求 |
| --- | --- |
| 投资结论 | 一段明确判断：值得投资、价格尚无吸引力、暂不建议或无法合理估值；注明行情与财报时点；仅在依据足够时提供价值、买价与条件IRR，否则明确暂不能合理估值，旧模型数字须显著标为条件对照。不要再附三维度摘要、重复证据卡或改写说明。 |
| 商业模式 | 一段赚钱机制，再逐项分析长期护城河、长期毛利率、长期净现金流；给公司专属判断与反证。 |
| 企业文化 | 用有日期的承诺兑现、诚信、利益取舍、渠道/客户待遇及资本配置评价，不以口号或一次分红认证优秀。 |
| 安全边际与估值 | 评价未来盈利与现金清晰度，说明必要回报率依据；先判断未来现金能否形成可信量级，再决定能否估值与计算IRR；不为填表强行预测。 |
| 其他思维观点 | 巴菲特、芒格、散户乙、韦尔奇各用一段给独立补充/异议；超级鹿鼎公按十六字方针给条件操作。 |
| 关键风险与后续验证 | 3—5个能改变判断的指标与失效条件，保留预测偏差记录，不复述结论。 |

标题用正常中文，不照搬解释性括号，不用第一关/第二关或“懂不懂、好不好、便不便宜”等标签。目录直接采用实际章节标题并保持可访问：桌面吸顶，手机可滑动固定目录，跳转不能遮住标题。

## 二、商业模式必须回答的三个问题

1. **长期护城河**：用户需要的差异化是什么，为什么持续付费，竞争者为何难以抢走，什么改变会侵蚀它？不能用行业名、历史称号、窖龄或技术名词代替经济机制。
2. **长期毛利率**：用多年、跨周期及产品结构解释替代性与定价能力，结合销售费用和维持竞争力的成本；不以单期高毛利直接认证模式，不设跨行业统一阈值。
3. **长期净现金流**：重点是理解企业未来持续创造股东现金的能力；未来利润和增速都不是当前已知事实，历史仅供参考校验。由消费者需求、竞争与定价、成本费用和必要投入，判断现金可能维持、改善或下降，解释依据、幅度边界和反证。仅在可形成有依据的粗略量级时估值；否则明确暂不能合理量化，不强填增长率、现金转化率、寿命或衰退曲线。经营现金、普通股可分现金和实际分红分开；标为“假设”不等于假设已有依据。

形成“持续差异化→竞争保护→合理毛利→长期净现金”的因果链。库存、动销、返利与短期业绩为检验它的证据，不是商业模式本身。不仅写“尚待验证”，也不因研究尚未做完就判断企业不可理解。

## 三、商业模式与企业文化排除清单

先主动核查以下排除事项；有实质证据证明是结构性或持续性问题时，停止该视角的积极买入论证，不能用低价、高毛利或好业绩抵消：

- 无持续差异化，只能依赖价格战。
- 缺乏真实产品价值，长期靠营销、补贴或压货维持需求和增长。
- 以“性价比”掩盖无法形成合理经济回报的低价竞争。
- 管理层反复撒谎、隐瞒、侵占利益，或持续为短期利益损害消费者和长期股东。

广告、促销、低售价或正常融资本身不是否决证据；个别差错与不可修复的模式/文化缺陷分开。未取得证据不等于通过，也不等于有罪。写明“未发现实质否决证据／存在待核信号／已触发否决”及公司专属依据；这是公司研究判断，不是个人不为清单教育。

正面、负面行为和未核事项分开。面对短期利润冲突时的反复选择比自我评价更重要；主动找诚信和利益冲突反证，但不能因缺材料推定文化差。确认的实质负面不能被便宜或好业绩抵消。

本人原则、第三方归纳、研究者实现、本人特定时点意见及当前公司事实分开。公开持仓须核身份、原文、日期与披露范围，不默认每日更新或完整公开，不跟随持仓替代研究。

## 四、安全边际、买入价与IRR

本项目标题“安全边际”侧重公司未来利润与现金的可见程度，不是判断用户个人能力圈。品牌、竞争、周期、负债与资本投入决定不确定性；用它解释情景区间和主观必要回报率。结构性风险不因提高折现率而自动可投。

估值依次说明经营买入代价、当前正常盈利、未来5—10年及更长期走向、股东回报途径和机会成本。参考买入区间必须有经营假设，说明什么事实会令区间失效；不能为得到漂亮排名或买入结论调参。无可靠价值锚时不给精确买点。

stock-research网站现有共同模型为shareholder-irr-v1：买入1股、逐年领取现金分红、第十年末按EPS与退出PE卖出、分红不复投。在该网站中，页面、Markdown和排名用同一引擎；其他使用环境不能假装已运行或接入此引擎。期末价值不是保证，IRR不是概率校准的预期收益，也不额外叠加做T或回购收益。

现金流折现是价值原理，不是必须输出精确价格的填表任务。能够合理粗估时，价值、参考买价和IRR应基于一致的未来经营及股东现金假设，十年后出售价值需与剩余现金能力相容，不能无依据另套PE。不能形成可信量级时不新增折现估值；旧十年模型只作明确标注的条件对照，不能称已验证预期收益或综合买点，也不为统一结果反向调参。股权现金与股权折现率匹配，不叠加分红、退出价或未经核清的多余现金。

现金与债务须按实质处理：集团/母公司不相加；受限和必要营运资金不是多余现金；经营现金减购建不是已扣完其他义务的普通股现金。未来未知分红不直接填零；规划、批准、实施与买入后领取权分开，已除息股息不重复计入。

## 五、其他五位的观点与操作建议

其他视角简洁、具体，不要求人为制造分歧，也不重复商业模式正文：

- 巴菲特：所有者收益、增量资本回报、资本配置与价值。
- 芒格：激励、交互风险、反证与永久损失。
- 散户乙：企业最坏路径、现金分配与退出价格依赖。
- 韦尔奇：战略聚焦、责任/激励和真实执行成果。

超级鹿鼎公按四步：

合并为一个小节、四条简短意见，不展开四个长章节或重复估值表。依次回答投资价值、宏观与股价趋势是否支持介入、当前新增仓位、做T价差与观察周期。仓位区分新增与存量；无个人组合不声称最优百分比。交易参数须注明行情截止日、波动依据和停止条件；未回测的观察窗口不得写成预测周期或固定获利规则，不适合时明确不做。

| 方针 | 报告内容 |
| --- | --- |
| 价值选股 | 是否进入候选池，盈利底线与失效事实；悲观情景不是保底。 |
| 趋势选时 | 分开经营、行业和市场趋势，给介入/等待条件；缺当前量价或技术证据就不编均线买点。 |
| 估值定仓 | 给观察、分批、增加/降低配置的价格或估值条件；缺个人组合信息不报虚假最优仓位。 |
| 波动降本 | 明确是否适合做T/网格；给预算、底仓/交易部分、买卖/停止条件，不适合就建议不做。 |

这些是研究者依据其方法形成的方案，不冒称本人原话。交易须考虑费用、滑点、踏空和价值锚变化；不把基本面失效当作无限补仓机会。重大异议需反馈开篇结论。

## 六、资料、去重与验收

已接入妙想时优先获取行情/财务及公告，失败或不完整时缩小重试一次，仍不可用再用公开来源；未接入时如实说明并直接用可访问的公开来源，不虚构两次调用；公告、财报与交易所优先。与研报冲突时回原披露，不将研报历史列错数继续当事实。读到的原件注明页码、币种、期间、单位及归属；季度预告和预约不是实际财报。

研报用于比较假设与分歧，不拿评级或均值当结论。数据只在最相关位置充分展开，其他地方回指；历史审计、模型细表和完整来源可作附录/折叠。顶部给答案，正文解释原因，末尾列验证，不在每章重新总结整篇结论。

网站新增或重做完整报告采用company-study-v2六章；未迁移旧报告继续兼容，不批量强迁移。具体ID、来源索引与归档协议见仓库docs/research-framework.md。纯问答按实际问题回答，不强套完整报告篇幅。

更改金融数据须记录实际范围、旧新值与来源；结构变更不冒充数据刷新。交付须列出已核事实、研究推导、假设和缺口，明确哪些旧参数未重估。网站更新默认覆盖当前报告，并同步所有相关出口；未经用户授权不提交、推送或部署。

## 七、交付前自查

- 六章是连贯公司研究，非模板拼接；每个重要判断有公司专属理由、证据和反证。
- 历史只是参考，未来利润/增速未伪装成事实；无法量化时不强给价值或IRR。
- 商业模式、文化排除事项已逐项核查，重大负面没有被估值抵消。
- 价值、买价与IRR使用相容的现金和剩余价值假设；旧条件模型没有包装成可靠买点。
- 其他五位简洁独立，鹿鼎公四条，没有虚构本人意见、最优仓位或交易周期。
- 来源真实可定位，期间、币种、股本、单位和除息权利一致；缺信息明确说明。
- 本地/Work交接说明写入文件、参数是否变化、测试及未完成项，不以模型检查通过代替研究可靠性。
