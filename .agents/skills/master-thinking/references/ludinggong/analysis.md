# 分析与计算

本文件提供研究实现 D，除标明历史发言的部分外，不声称是作者的固定模型。四步以 ../deep_models/ludinggong.md 为准。

## 盈利底线

先重建行业正常供需，不先替已持仓企业证明便宜。用量、价、单位成本、固定成本、税率、融资成本与资本支出解释利润情景。将“底线”当作可推翻的估计；需求永久变化、竞争地位下降或成本上升时，必须下修。

对白酒等行业，分开厂家发货、渠道库存、消费者实际消费与终端价格；报表利润与终端需求不等同。对航运、煤炭、电解铝，使用不同运价或商品价格下的利润，而非直接外推景气高点。对水电与收费资产，核对来水、经营期限、定价和维护投资。

经营现金流受营运资金影响，不能把单季变化直接视为长期能力。自由现金流通常按经营现金流减资本支出估算；区分维持与扩张投资，披露无法拆分时用范围，不默认为零。归母净利润、经营现金流、自由现金流、实际现金分红不能互换。

## 估值工具

1. 正常 PE = 当前股权市值 / 正常归母利润。
2. 低谷 PE = 当前股权市值 / 悲观情景归母利润。亏损时 PE 失效。
3. 税前股息率 = 可持续每股现金分红 / 当前股价；税后收益按账户和市场实际规则核查。
4. 盈利收益率 = 正常利润 / 股权市值；不能自动当可分配现金回报。
5. 分红比例 p、目标股息率 y 的简单关系：PE = p/y，前提是利润稳定、分红真实可持续且没有其他差异。
6. 现金流估值以逐年可分配现金流折现，加折现后终值与非重复计算的净现金。统一股权/企业价值口径，避免同时加净现金又重复扣同一债务。

2023-08-22 的历史例子使用50%分红和4%股息得12.5PE；它是带条件的估值演示，不是所有公司、利率环境和时期的买入线。原文对茅台未来利润的处理属于作者估值近似，不是经过逐年折现的标准DCF。实际建模不要照抄“未来利润直接算当前利润”或把增长率直接抵消贴现率。

## 价值区间和仓位

给出：
- 保守盈利/分红、正常盈利/分红及增长可见程度。
- 每个情景适用的估值方法和利率假设。
- 股价相对区间的位置：低估、合理、昂贵或无法判断。
- 在本组合中的最大预算、已有敞口和相关性。

以下只是 D 示例：单股仓位30%，该股跌50%时直接损失约组合的15%；若其余持仓同受消费下行影响，总损失可能更大。盈利弹性较大的公司可限制预算以控制损失，并不要求永远排除。不得根据作者一次历史持仓，反推适合用户的仓位。

低估又变便宜时，重新检查利润、现金流和判断置信度，再讨论加仓。过去的成本价不是价值锚。预算没有余量时，不以“摊薄成本”制造额外资金来源。

## 降本和总收益

净做T收益 = 卖出所得 - 对应交易批次购入成本 - 费用税费。注明配对方式，不把原底仓成本当作新交易成本。

卖出盈利、分红、现金余额和剩余股票共同计入组合总价值。剩余持仓显示成本降低并不意味着总资产增加；分红除息也不是凭空增益。复投改善长期现金流取决于企业持续盈利、真实分红与复投价格；同期净值可能下跌。

和不交易策略比较时，计入费用、滑点、踏空、额外资金占用及机会成本。不存在交易数据或可靠回测时，不能宣称做T必提高收益。

## 查证

分析现实标的时获取最新公开资料和多期历史数据。优先原始公告，引用独立第三方只用于补充。说明股价时点、A/H/B股、人民币/港币及是否复权。对重大结论给能使其失效的事实，不用“安全”代替证据。
