# 大师思维

使用中文，基于最新可核实事实和原始资料作出独立研究判断。完整评估且用户未指定视角时按下述主次使用六位，不作等权拼接；指定一位或多位则仅聚焦指定者。鹿鼎公、超级鹿鼎公、十六字方针和“鹿鼎公投资法”均路由到鹿鼎公模型。简短问题按问题范围回答，完整评估执行下列流程。不冒充投资者本人，不把研究结论当作其当前公开意见。

## 默认研究优先级

1. **段永平为第一主线**：先过不为清单、能力圈、商业模式与文化，再判断未来现金与价格；报告的核心命题、主要论证和综合判断优先沿此展开。
2. **巴菲特、芒格为第二层检验**：以所有者收益、护城河、资本配置和安全边际检验价值，以激励、反向思考及永久损失检验决策。发现与主线冲突的证据应明确展开，不为维持主线而省略。
3. **散户乙、韦尔奇、超级鹿鼎公仅作辅助**：分别补充持有人生存与回本、组织执行、盈利底线及条件性操作分析；只展开与公司相关的问题，不强凑等长章节，不用辅助信号替代生意、文化与价值判断。

这是用户选择的研究使用顺序，不是投资能力或思想高下排名，不设机械权重或加权评分。用户更重视段永平较贴近当下市场的公开交流与可核实持仓线索；实际使用须逐条核对身份、原文、日期与披露范围，不默认每日更新或完整公开持仓，不以年龄、活跃度或持仓本身代替公司证据。巴菲特、芒格的历史框架仍独立有效，不依赖其是否继续公开活动。指定单一视角时服从用户指定；任何视角揭示的重大反证、资金或生存风险都不得因优先级较低而被忽略。当前结论结构和网站六章结构保持不变。

## 全局与项目统一主版本

唯一主版本为 `https://github.com/liuyi-hubei/stock-research/tree/main/.agents/skills/master-thinking`。该仓库是框架的存放与维护位置，不限制使用范围；ChatGPT/Codex 的全局“大师思维”入口与项目“大师视角”入口均使用这套框架。项目检出中的 `.agents/skills/master-thinking/` 是项目级安装；全局 Skill 或插件携带的技能是入口或镜像，不另行发展第二套框架。修改方法时先更新主仓库，再同步镜像并比较 `references/framework-manifest.json` 的逐文件 SHA-256；只更新镜像不算完成跨端保存。多个同名入口同时存在时优先使用本仓库已核对的主版本，不混用旧规则；旧插件没有上述路由规则时须更新其源文件或重新安装，不能假定账号登录会刷新所有本地插件缓存。

每个新会话首次调用全局或项目“大师思维／大师视角”时核对主仓库版本：本地有项目检出时读取项目技能；没有检出时由可用 GitHub 或联网工具读取主版本及所需引用，比较镜像清单。发现差异就读取主版本用于当前研究；不得把旧镜像称为最新。无法联网时使用可用快照并说明未核对主仓库。Git 同步前检查本地状态，不覆盖未提交工作，不自动解决冲突；换电脑需先 clone，同步现有检出使用 `git pull --ff-only`，不是账号登录即自动同步。

编写完整个股报告时必须读取[个股研究报告写作规范](references/个股研究规范.md)，这是当前写作主规则，适用于本地agent与ChatGPT Work；解释框架或简短问答无需套完整报告。stock-research网站的工程结构、原收益引擎和参数权限另服从仓库AGENTS.md及docs/research-framework.md。六视角是分析工具，不等权拼接，不自动另建模型或调参。

公开主仓库同步框架、模型、来源索引与研究性归纳，不附书籍和第三方文章的全文语料；个人环境已有的 `references/documents/` 为可选原始资料，不属于跨端已同步的框架文件。需要关键原文时先查可用个人资料，再按可访问的公开原始来源核验。缺原文时说明限制，不把缺包说成已阅读，也不因没有私有语料而拒绝解释方法。不得将个人资料全文作为同步副作用公开上传。

阅读 `references/data-sourcing.md`。先辨认公司、代码、市场、币种和 A/H/ADR 股份类型，确认当前日期、报价时间和最新实际披露财报。

没有联网或当前数据工具时说明限制，允许用户提供带日期的数据继续研究；不能以旧知识冒充最新行情，不给缺少价格依据的当前推荐指数。

## 六位独立研究

各位共享已核实的公司事实，分别完成“问题—证据—估值—判断—反证”。

| 视角 | 核心研究问题 |
| --- | --- |
| 巴菲特 | 护城河能维持多久，正常化所有者收益与再投资、资本配置意味着多少每股价值 |
| 芒格 | 激励、心理误判和商业机制会如何相互作用，什么造成永久损失，是否太难 |
| 段永平 | 商业模式和文化是否看懂，消费者为何持续付费，未来现金流是否支持今天的价格 |
| 散户乙 | 最坏路径能否生存，分红和回本是否可持续，融资或杠杆会不会迫使持有人退出 |
| 韦尔奇 | 人才、坦诚、聚焦和执行是否转成真实经营成果，改善是否已经被价格反映 |
| 超级鹿鼎公 | 可持续盈利底线是否可靠，经营与市场趋势如何，价格和确定性支持多少预算，波动交易能否在费用后降本 |

韦尔奇提供管理与组织视角；额外股票估值模型应标为研究者补充，不能伪称其本人提出。

明确要求逐位评估时，每位分别给出公司具体证据、适用的估值口径及假设、当前价格判断、买入或持有前提、失效条件与后续验证。默认综合研究按主次整合这些检验，不强制六套完整输出。不能把同一套买入建议换人名，也不必强迫六人分歧。相同结论须有独立理由。

判断可以是值得深入研究、价格有吸引力、等待证据、价格透支或看不懂。先评生意，再评价格；不要用机械 PE 阈值或单个财务指标决定买卖。对周期公司使用正常化盈利，对不同金融和资产型公司调整指标，不把半年数据简单乘二。

价值区间必须有可解释假设，分清每股与整体价值、币种与股份类别，说明敏感性；证据不足就不报精确目标价。用户需要推荐指数时，使用 0—5 分、半分步长，逐人说明评分原因和数据日期；评分是研究相对优先级，不是本人评级或获利概率。不给无依据的仓位比例。

## 段永平分析模块

段永平视角按[完整模型](references/deep_models/duan_yongping.md)理解不为清单、能力圈、商业模式与文化、估值及持有纠错的关系。完整报告采用写作规范的六章，不把个人纪律或用户能力圈作为正文，不使用口语或闯关式命名；“安全边际”评价公司未来现金的清晰度。框架原始概念与报告展示标题分开。

做事原则和不为清单用于内部研究纪律，默认不在个股正文输出个人认知教育、杠杆提醒或通用行为清单；仅用户明确询问方法、个人配置或具体风险问题时展开。公司报告直接分析企业未来、商业模式三问、文化行为和估值，不把内部约束冒充公司研究内容。

商业模式必须逐项分析：长期护城河（用户需要的差异化及竞争者为何难抢）、长期毛利率（替代性与定价能力）、长期净现金流（利润、必要投入与资本回报）；不能用渠道库存、短期业绩或单次分红检查代替。文化独立检验承诺兑现、是非取舍、诚信及利润之上的追求，主动寻找负面行为。先形成生意认识，再以数据验证，不把研究未完成直接写成企业不在能力圈。

未来利润与增长率不是已知事实，历史只作参考；先理解现金创造机制，有依据才粗估量级。不能为完成DCF任意填增长、转化率、寿命与衰退曲线；无可信量级时明确暂无法合理估值。价值、买价与IRR须有相容现金及剩余价值假设；旧模型阈值只能作条件对照，不能当可靠买点。商业模式与文化的实质排除条件见写作规范及深度模型，低价不能补救。

理解或企业质量不能成立时停止积极买入论证，不以便宜补救。估值按经营买入代价、当前盈利、未来5—10年及更长期走向、股东回报途径四步粗估，结合机会成本；持有按当前机会重评，与成本无关。具体上下文边界见模型及[来源说明](references/duan-framework-source.md)：不把1/6仓位、12倍PE、总负债净额或某时点案例机械化，也不把研究者财务实现伪称本人原话。原始资料仍保留，不以替换模型覆盖原文。

## 鹿鼎公四步模块

遵循 `references/deep_models/ludinggong.md`：价值选股 → 趋势选时 → 估值定仓 → 波动降本。分别判断经营、行业与市场趋势；先判断价值可知程度，再谈仓位或交易，不能为交易强造盈利和现金情景。综合报告中只保留一个小节四条简短意见；没有依据时明确等待或不做，做T不是必选动作。

不使用统一 PE、股息、跌幅或均线买卖阈值；分红承诺与可持续分红分开，红利复投、做T盈亏、持仓显示成本和组合总收益分开。盈利恶化时更新估值并允许退出，不通过无限补仓或网格挽救失效判断。具体预算需结合已知资金、用款和相关敞口，资料不足给条件方向；未获明确指令不执行真实交易。

鹿鼎公来源等级 A（已读作者账户正文）、B（已读转载正文，未全面核对原帖）、C（他人解释，仅线索）、D（研究实现）必须保留。580条目录不等于580篇已读，34份全文文档也不等于全量雪球原帖。主仓与游戏仓、农历与自然年分开，不宣称无年度亏损、永不止损或固定年化收益。

## 原文归因

明确区分“本人直接表达”“依据框架推演”“研究者补充”。引用持仓或交易需核实对象、日期、来源和是否仅为历史记录。过去买入不等于现在持有，也不等于认可今天价格；不得从报道推算未经披露的持仓金额。

段永平雪球观点已整合入随包正式语料，日常不要求重爬。只归因他本人的文字，不把被回复者或被转发者的话当成他的意见。新信息若未在包中，只能作为另行核实的当期证据，不能声称知识包自动更新了。

## 输出与检查

完整研究依次呈现：标的与日期、关键事实及来源、按默认优先级整合的分析（用户要求时逐位独立评估）、分歧与估值假设、后续验证。按实际信息量组织篇幅。对话问题可简短回答，不强行输出完整报告。

交付前检查数据可追溯、同比和估值可复算、时点一致、归因准确、每位结论有公司专属依据。保留证据不足和不确定性。公开来源给真实链接；随包资料给文档编号与段落说明，不输出用户无法打开的本机绝对路径。没有公开链接就说明是随包文献，不伪造链接。

只在用户要求时保存报告、更新知识或网页。调用本技能不会自动改动本地股票项目、发布站点或共享资料。随包材料为用户已有资料的个人使用快照，公开分发前应另行确认材料的分发权限。
