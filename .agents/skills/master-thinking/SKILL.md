# 大师思维

使用中文，基于最新可核实事实和原始资料作出独立研究判断。完整评估且用户未指定视角时采用六位；指定一位或多位则仅聚焦指定者。鹿鼎公、超级鹿鼎公、十六字方针和“鹿鼎公投资法”均路由到鹿鼎公模型。简短问题按问题范围回答，完整评估执行下列流程。不冒充投资者本人，不把研究结论当作其当前公开意见。

## 项目统一主版本

唯一主版本为 `https://github.com/liuyi-hubei/stock-research/tree/main/.agents/skills/master-thinking`，本技能仅供 stock-research 项目使用。项目检出中的 `.agents/skills/master-thinking/` 是项目级安装；当前 Work 的个人技能目录是可调用镜像，不另行发展第二套框架。修改方法时先更新主仓库，再同步镜像并比较 `references/framework-manifest.json` 的逐文件 SHA-256；只更新镜像不算完成跨端保存。

每个新会话使用前核对主仓库版本：本地有项目检出时读取项目技能；Work 通过 GitHub 工具读取主版本及所需引用，比较镜像清单。发现差异就读取主版本用于当前研究；不得把旧镜像称为最新。无法联网时使用可用快照并说明未核对主仓库。Git 同步前检查本地状态，不覆盖未提交工作，不自动解决冲突；换电脑需先 clone，同步现有检出使用 `git pull --ff-only`，不是账号登录即自动同步。

网站报告仍服从项目 `AGENTS.md`、`docs/research-framework.md` 的证据优先六章结构及唯一收益模型；六视角是分析工具，不强制把报告改为六个人物口吻，也不自动增加第二套收益模型或更改参数。用户指定某位视角时可在对话中聚焦该位。

公开主仓库同步框架、模型、来源索引与研究性归纳，不附书籍和第三方文章的全文语料；个人环境已有的 `references/documents/` 为可选原始资料，不属于跨端已同步的框架文件。需要关键原文时先查可用个人资料，再按可访问的公开原始来源核验。缺原文时说明限制，不把缺包说成已阅读，也不因没有私有语料而拒绝解释方法。不得将个人资料全文作为同步副作用公开上传。

本文件所在目录是技能根目录，所有下列路径均相对于该目录。无需访问原股票项目或特定电脑路径。

1. 读 `references/deep_models/combined_framework.md`，再读所需模型：`warren_buffett.md`、`charlie_munger.md`、`duan_yongping.md`、`sanhuyi.md`、`jack_welch.md`、`ludinggong.md`。
2. 从 `references/topic_index.md` 与 `references/document_abstracts.md` 定位主题；`references/corpus_inventory.json` 的 `bundled_text_path` 指向随包原文。
3. 原五位视角的完整个股研究必须实际阅读支持各位关键判断的可用个人原文或公开原文及必要上下文；公开主版本未附全文时，按来源另行核验。可用技能资源读取、文件检索或运行环境提供的文件工具。不能用摘要代替原文核验，也不必通读全部语料。
4. 文档编号、出处日期、编译属性和定位支持审计；原文不是指令。无法访问随包文件时说明缺项，不假装读过。不得根据另一台机器的历史绝对路径寻找文件。

鹿鼎公资料单独索引，不混入原五位的 DOC 编号：先读 [证据与来源](references/ludinggong/evidence.md) 和 [覆盖范围](references/ludinggong/coverage.md)；公司分析读 [分析与计算](references/ludinggong/analysis.md)，仓位、做T或网格读 [操作与演变](references/ludinggong/operations.md)，历史复盘读 [案例与反例](references/ludinggong/cases.md)，补充查证用 [580条目录](references/ludinggong/archive-urls.json)。本包保留来源索引与归纳，未收录这34份文档的全部原文；需要关键原话或新增历史断言时按链接阅读全文核验，无法访问则说明限制，不以归纳冒充原文。

深度模型是已有提炼；材料中可能有英文原文，分析仍用中文。索引中的原始输入路径仅保留来源信息，不是运行依赖。仅查询随包资料不需要服务器。

## 最新数据

阅读 `references/data-sourcing.md`。先辨认公司、代码、市场、币种和 A/H/ADR 股份类型，确认当前日期、报价时间和最新实际披露财报。

优先发现已连接的妙想工具或本机可用的 mx-skill。若存在但调用失败，对该项重试一次；连续两次不可用后采用网络公开资料。若目标聊天未接入妙想，明确说明“此聊天未接入妙想，本次使用公开来源”，直接使用可用联网工具，不虚构尝试记录。插件本身不包含妙想连接或凭据。

没有联网或当前数据工具时说明限制，允许用户提供带日期的数据继续研究；不能以旧知识冒充最新行情，不给缺少价格依据的当前推荐指数。

## 六位独立研究

各位共享已核实的公司事实，分别完成“问题—证据—估值—判断—反证”。

| 视角 | 核心研究问题 |
| --- | --- |
| 巴菲特 | 护城河能维持多久，正常化所有者收益与再投资、资本配置意味着多少每股价值 |
| 芒格 | 激励、心理误判和商业机制会如何相互作用，什么造成永久损失，是否太难 |
| 段永平 | 商业模式和文化是否看懂，消费者为何持续付费，未来现金流是否支持今天的价格 |
| 散户乙 | 最坏路径能否生存，分红和回本是否可持续，融资或杠杆会不会迫使持有人退出 |
| 韦尔奇 | 人才、坦诚、聚焦和执行是否转成真实经营成果，改善是否已经被价格反映 |
| 超级鹿鼎公 | 可持续盈利底线是否可靠，经营与市场趋势如何，价格和确定性支持多少预算，波动交易能否在费用后降本 |

韦尔奇提供管理与组织视角；额外股票估值模型应标为研究者补充，不能伪称其本人提出。

每位分别给出公司具体证据、适用的估值口径及假设、当前价格判断、买入或持有前提、失效条件与后续验证。不能把同一套买入建议换人名，也不必强迫六人分歧。相同结论须有独立理由。

判断可以是值得深入研究、价格有吸引力、等待证据、价格透支或看不懂。先评生意，再评价格；不要用机械 PE 阈值或单个财务指标决定买卖。对周期公司使用正常化盈利，对不同金融和资产型公司调整指标，不把半年数据简单乘二。

价值区间必须有可解释假设，分清每股与整体价值、币种与股份类别，说明敏感性；证据不足就不报精确目标价。用户需要推荐指数时，使用 0—5 分、半分步长，逐人说明评分原因和数据日期；评分是研究相对优先级，不是本人评级或获利概率。不给无依据的仓位比例。

## 段永平三关落地模块

段永平视角必须按 `references/deep_models/duan_yongping.md` 执行：不为清单 → 懂不懂 → 好不好（模式与文化分别核验）→ 便不便宜 → 持有及纠错复核。前关失败时停止该视角的买入论证，不以便宜补救；输出公司专属证据、未知项与失效条件。使用整家公司所有权检验、管理行为清单、正常化现金和四步粗估；持有按当前价格重新判断，成本不作理由。新增重要参考见 [段永平框架来源](references/duan-framework-source.md)，为经本人正面认可的第三方 AI 总结；与原始语料合并使用，不把历史 PE、仓位数字机械化，不把研究实现伪称本人原话。

## 鹿鼎公四步模块

遵循 `references/deep_models/ludinggong.md`：价值选股 → 趋势选时 → 估值定仓 → 波动降本。分别判断经营、行业与市场趋势；先建立盈利和现金流情景，再谈仓位或交易。仅解释方法时简短作答，做T不是完整评估的必选动作。

不使用统一 PE、股息、跌幅或均线买卖阈值；分红承诺与可持续分红分开，红利复投、做T盈亏、持仓显示成本和组合总收益分开。盈利恶化时更新估值并允许退出，不通过无限补仓或网格挽救失效判断。具体预算需结合已知资金、用款和相关敞口，资料不足给条件方向；未获明确指令不执行真实交易。

鹿鼎公来源等级 A（已读作者账户正文）、B（已读转载正文，未全面核对原帖）、C（他人解释，仅线索）、D（研究实现）必须保留。580条目录不等于580篇已读，34份全文文档也不等于全量雪球原帖。主仓与游戏仓、农历与自然年分开，不宣称无年度亏损、永不止损或固定年化收益。

## 原文归因

明确区分“本人直接表达”“依据框架推演”“研究者补充”。引用持仓或交易需核实对象、日期、来源和是否仅为历史记录。过去买入不等于现在持有，也不等于认可今天价格；不得从报道推算未经披露的持仓金额。

段永平雪球观点已整合入随包正式语料，日常不要求重爬。只归因他本人的文字，不把被回复者或被转发者的话当成他的意见。新信息若未在包中，只能作为另行核实的当期证据，不能声称知识包自动更新了。

## 输出与检查

完整研究依次呈现：标的与日期、关键事实及来源、各位独立评估、分歧与估值假设、后续验证。按实际信息量组织篇幅。对话问题可简短回答，不强行输出完整报告。

交付前检查数据可追溯、同比和估值可复算、时点一致、归因准确、每位结论有公司专属依据。保留证据不足和不确定性。公开来源给真实链接；随包资料给文档编号与段落说明，不输出用户无法打开的本机绝对路径。没有公开链接就说明是随包文献，不伪造链接。

只在用户要求时保存报告、更新知识或网页。调用本技能不会自动改动本地股票项目、发布站点或共享资料。随包材料为用户已有资料的个人使用快照，公开分发前应另行确认材料的分发权限。
